1. 효빈위키 [편집]

1.1. 효빈위키는 다른 위키들과 어떤 차이가 있나요? [편집]

🔎 자세한 내용은 효빈위키/다른 위키와의 차이점 문서를 참고하십시오.

1.2. 효빈위키에 부정확한 정보가 있습니다. [편집]

효빈위키는 '위키' 형식의 웹사이트이므로, 수정 자격이 따로 존재하지 않고 기본적으로 누구나 자유로이 수정 가능합니다.[1] 효빈위키의 모든 페이지에 "효빈위키는 백과사전이 아니며 검증되지 않았거나, 편향적이거나, 잘못된 서술이 있을 수 있습니다."는 안내 문구가 있는 이유입니다.
부정확한 정보는 여러분이 직접 삭제 및 교정하실 수 있습니다. 만약 부적절한 편집이라고 오해받을까 걱정된다면, 편집 요약을 적극적으로 사용해 보시는 것을 권합니다. 편집 요약은 편집창 하단에서 남길 수 있습니다. 필수는 아니지만 근거가 될 수 있는 외부 링크를 함께 남기시면 더욱 신뢰성 높은 편집을 할 수 있습니다.
편집 요약을 남겼음에도 다른 사용자와 의견이 충돌할 경우 토론을 진행하실 필요가 있습니다. 이에 관해서는 토론 도움말을 참고해주세요. 사용자간의 의견 수렴을 위하여 토론에 '[의견 수렴]'이라는 머리말을 붙여 의견 수렴용 토론을 열 수 있는데 일반 토론과는 달리 합의안 제시가 없습니다.

1.3. 저는 문서가 다루는 본인 또는 관계자인데, 문서에 우려되는 내용이 있습니다. [편집]

🔗 관련 문서: 효빈위키:권리침해 도움말
우선, 효빈위키는 당사자의 편집을 제한하고 있지 않습니다. 그러므로 부적절한 서술에 대해서는 직접 삭제 혹은 편집하실 수 있고, 편집 요약을 남기실 수 있습니다.
그럼에도 자신과 관련된 문서(회사, 유튜브 채널 등을 포함)에 적힌 사생활 침해성, 허위성, 명예훼손성 서술이 계속될 것으로 예상되거나 어떤 이유로든 문서가 작성되는 것 자체를 원치 않으실 경우, 운영사 측과 이메일로 연락하여 임시조치를 취할 수 있습니다. 효빈위키 용어로 '임시조치'란 운영사 측에서 문서에 대해 권리를 가진 당사자가 당사자와 직접적으로 연관된 특정 문서의 모든 내용을 삭제한 후 임시조치가 이루어졌음을 표시하는 문구만 30일 동안 남기는 것입니다. 요청 시 요청 사유에 관계없이 임시조치가 이루어집니다. 단, 해당 문서에 유의미한 기여 내역이 있는 기여자는 IP 및 개인식별정보 영구 분리 보관에 동의한다면 30일 이내에 임시조치에 대한 이의를 제기할 수 있습니다.

2.1. 계정명을 변경할 수 있나요? [편집]

🔎 자세한 내용은 효빈위키:계정 문서의 2.1번 문단을 참고하십시오.
네, 가능합니다. 계정 생성 이후에도 원하는 닉네임으로 변경할 수 있습니다. 단, 변경 후 30일 이내에는 다시 변경할 수 없으며 변경을 취소할 수 없습니다. 변경 후 이전 닉네임은 타인이 즉시 재사용할 수 있습니다. 닉네임을 변경해도 UUID는 그대로 유지되기 때문에, '내 문서 기여 목록'[2]은 변함없이 모두에게 공개됩니다. 자세한 내용은 관련 공지를 확인해 주세요.

3. 문서 열람 시 [편집]

3.1. 문서가 훼손된 것 같습니다. [편집]

우측 상단에 '역사' 버튼을 클릭 후 '비교' 기능을 사용하여 문서를 훼손시킨 리비전을 찾아내고 그 이전의 리비전으로 되돌리기 하시면 됩니다. 문서 훼손자의 IP 또는 계정명에 취소선이 그어져 있다면 이미 차단된 상태이며 그어져 있지 않다면 신고 게시판에 제재 요청을 하시면 됩니다.
차단되지 않은 사용자가 계속해서 문서 훼손을 시도한다면, 이에 일일이 대응하지 마시고, 신고 게시판에 신고해 주세요.

3.2. 문서가 훼손되었는데 편집 창에는 안 보입니다. [편집]

해당 문서에 틀이 포함되었는지 확인해 보세요. 포함되었다면, [include(xx)] 문법으로 해당 문서에 나타나는 다른 문서가 훼손된 것입니다. 대개 틀이 훼손됩니다. 이 경우 편집 창에서 include된 틀이나 문서의 이름을 찾은 뒤 해당 문서의 역사 또는 피신고자의 기여 목록을 첨부해서 신고 게시판에 신고하시면 됩니다.

3.3. 리다이렉트 순환 오류가 있습니다. [편집]

#redirect 태그를 잘못 써서 원래 문서를 수정할 수 없게 되었을 때는, 주소창에 'https://hyobin.wiki/history/원래문서'를 입력하고 히스토리 화면으로 이동해서 이전 버전으로 복구하거나, 'https://hyobin.wiki/edit/원래문서'로 직접 편집할 수 있습니다.
또는, 리다이렉트로 문서에 넘어왔을 때는 "(리다이렉트 문서)에서 넘어옴"이라는 멘트가 뜨는데, 여기에서 리다이렉트 문서의 이름을 클릭하면 순환 오류가 멈추게 됩니다. 이때 편집이나 삭제, 되돌리기를 하면 됩니다.

3.4. 문단이 생성되지 않습니다. [편집]

== == 문법에서 다음의 두 가지 중 하나가 잘못된 경우 문단으로 출력되지 않고 일반 텍스트로 출력됩니다.
  • ====사이에 공백이 없나요?
    • ex) ==개요==
      (내용)
      ==역사 ==
      (내용)
      == 사례==
      (내용)
  • 마지막 = 뒤에 공백이 있나요?
    • ex) == 개요 ==
      (내용)

3.5. 문단 번호에 0이 있습니다. [편집]

== == 문법에서 다음의 두 가지 중 하나가 잘못된 경우 문단 번호에 0이 나올 수 있습니다.
  • 최초 문단 문법에서 사용된 "=" 개수보다 더 적은 "=" 개수를 뒤에서 사용하지 않았나요?
    • ex) === 설명 ===
      (내용)
      == 대중매체에서 ==
      (내용)
  • 문단 문법에서 하위 단락을 분류할 때 중분류를 생략하고 대분류에서 곧바로 소분류로 넘어가지는 않았나요?
    • ex) == 개요 ==
      (내용)
      == 역사 ==
      (내용)
      ==== 근/현대의 동향 ====
      (내용)

3.6. 표가 깨져서 나옵니다. [편집]

  • 열의 마지막 || 뒤에 공백이 있나요?
    공백이 있으면 표 문법이 정상적으로 작동되지 않습니다. 공백을 제거해 주세요.
  • 모든 열의 첫 || 앞에 공백이 같은 바이트로 안 띄어져 있나요?
    열 앞에 공백이 동일하게 있지 않으면 표 문법이 정상적으로 작동되지 않습니다. 공백을 동일하게 하세요.
  • 테이블 합치기 문법에 따른 열과 칸의 변동을 고려하지 않았나요?

3.7. 영문 / 일문판 효빈위키 번역이 잘못되었습니다. [편집]

영문 / 일문판 효빈위키는 자동 번역을 기능을 통해 지원하고 있으며 별도의 개선 문의를 받지 않고 있습니다.

4. 편집·역사 페이지 [편집]

4.1. 문서 역사에서 멀리 떨어져 있는 로그를 비교하고 싶습니다. [편집]

비교하고 싶은 버전 중 한 버전을 체크한 뒤 페이지를 넘기면 체크한 버전이 지워지지 않고 페이지가 이동됩니다.

4.2. 문서 작성 후 생기는 역사에 +초록색과 -빨간색의 숫자 의미가 궁금해요. [편집]

(+123)은 RAW[3]를 기준으로 문서 길이가 증가했음을 의미하고, (-123)은 RAW를 기준으로 문서 길이가 감소했음을 의미합니다. (0)은 변동 없음을 뜻합니다. 숫자는 변동된 글자 수입니다.

4.3. 문서 역사에서 다른 IP보다 훨씬 길게 생긴 IP는 무엇인가요? [편집]

IPv6 이용자입니다. 8개의 16진수를 사용하고 콜론(:)으로 각 16진수를 구분합니다. 반면에 평소에 자주 보이는 4개의 10진수로 이루어진 아이피 이용자는 IPv4 이용자입니다.

4.4. IP에 초록색/노란색 취소선이 그어져 있어요. [편집]

초록색 취소선으로 표시된 아이피는 로그인 허용 차단된 IP이며, 노란색 취소선으로 표시된 아이피는 VPN 또는 IDC 대역 IP입니다.
로그인 허용 차단 IP는 일반적인 IP 대역 차단이랑 다르게 로그인한 상태면 효빈위키 이용이 가능한 IP 대역입니다.

4.5. CSRF 방지 토큰이 일치하지 않다며 편집이 안됩니다. [편집]

[오류!] CSRF 방지 토큰이 일치하지 않습니다. 다시 시도해주세요.
위와 같은 경고문이 나타나며 문서 편집이 되지 않을 때는 저장 버튼을 한 번 더 누르면 정상적으로 편집할 수 있습니다. 하지만 저장 버튼을 여러 번 눌러도 오류가 계속된다면, 미리보기 또는 RAW 편집에 들어간 뒤에 저장 버튼을 누르면 해결됩니다.
이래도 되지 않는다면, 주소창 왼쪽 자물쇠 버튼을 눌러 쿠키 메뉴로 들어간 다음, hyobin.wiki에서 사용 중인 쿠키를 모두 삭제해보세요. 모바일에서는 브라우저를 종료한 후 설정-개인정보 보호-인터넷 사용 기록 삭제 메뉴로 들어간 다음, 기간을 전체로 설정하고 쿠키를 삭제해 보세요.

4.6. 새로 만들 문서나 부실한 문서에 프로필 표를 추가하고 싶은데 혼자서는 어려워요. [편집]

인물, 지자체, 행정구역, 철도역 등 다양한 문서에는 최상단에 프로필 표(Infobox)가 있습니다. 여러분은 이 프로필 표가 어디서 나왔는지 궁금해하실 것입니다. 이것은 사용자가 커스텀으로 제작한 표일 수도 있고 틀:효빈시_정치인, 틀:도시철도역, 틀:효빈시_행정구역 등 각종 템플릿을 사용한 것일 수도 있습니다. 커스텀 프로필 표를 만드는 것은 난이도가 비교적 높은 작업이니, 효빈위키에 숙달되지 않으신 상태에서 프로필 표를 새로 만들고 싶다면 분류:템플릿에서 필요한 템플릿을 찾아 만드시길 권합니다.
틀:학교, 틀:버스_노선 등과 같이 규정상 강제되는 템플릿이 아닌 한 템플릿의 내용을 그대로 따라하지 않아도 전혀 문제가 없습니다. 템플릿을 뼈대로 하여 문서 특성에 맞게 프로필 표에 들어갈 항목을 적절히 변형시켜 보셔도 좋습니다.

6. 문서 이동 [편집]

6.1. 문서 제목을 바꾸고 싶습니다. [편집]

효빈위키에서는 문서 최상단에 표시되는 제목을 표제어라고 부릅니다. 표제어를 변경하기 위해서는 반드시 문서 이동 기능을 사용해야 합니다. 자세한 방법은 편집 도움말을 참고하시기 바랍니다.

6.2. 왜 문서 이동 기능을 사용해야 하나요? [편집]

문서 이동 기능을 활용하시면 편집 로그가 온전히 보존되어, CCL 상의 저작자 표시가 유지됩니다. 반대로, 복사 후 붙여넣기를 하여 문서 삭제식 이동을 하시게 되면, 과거 표제어로 되어 있었던 문서에 기여했던 분들의 목록을 확인하기가 어려워지게 됩니다. 문서 이동을 하려면 반드시 로그인을 해야 하며, 이동 사유에 대한 간단한 코멘트를 작성하시길 권장합니다.

6.3. 문서 이동이 안 됩니다. [편집]

가입한 지 15일이 지나야 이동할 수 있습니다. 관리자만 이동 가능한 경우가 아니라면 대리 요청은 별도로 받고 있지 않으니 로그인 후 이용하셔야 합니다.
가입한 지 15일이 지나서도 문서 이동 오류가 발생하면 다음을 참고해주세요.
  • "해당 문서가 이미 존재합니다." 메시지가 나타나는 경우: 옮길 문서명의 문서가 이미 존재하거나 있다가 지워진 경우입니다. 이 경우에는 '문서를 서로 맞바꾸기' 기능을 이용하면 됩니다.
  • "관리자만 가능하다"고 뜨는 경우: 이동하려는 문서가 관리자만 편집이 가능한 편집 제한 문서이거나, 관리자만 이동이 가능한 이동 제한 문서일 수 있습니다. 문의 게시판에 사유와 함께 ACL 해제 문의나 문서 이동 문의를 해주세요.

6.4. 문서 내용을 분리·병합하고 싶습니다. [편집]

문서 일부를 분리해 새로운 문서로 독립시키거나, 기존 문서를 다른 문서와 합치는 기능은 지원하고 있지 않습니다. 따라서 이런 경우에는 내용을 복사해서 붙여 넣는 방식의 삭제식 이동이 허용됩니다. 단, 틀:문서 가져옴 등 저작권 안내 틀을 통해 어느 문서 어느 리비전에서 가져왔음을 반드시 고지해야 합니다. 관련 도움말도 참고해 주세요.

7.3. 편집 권한을 상승시키고 싶습니다. 어떻게 해야 하나요? [편집]

편집 권한 상승은 ACL을 수정하여야 하며 관리자만 편집 권한 상승을 할 수 있습니다. 틀:접근 제한 같은 ACL 안내 틀은 편집 권한이 2단계 이상으로 상승되었을 때 안내 목적으로 부착하는 것이며, 해당 틀을 임의로 부착하는 것으로는 편집 권한을 상승시킬 수 없습니다. 해당 틀을 임의로 부착하면 편집권 남용으로 제재 대상이 될 수 있습니다.
문서의 편집 권한 상승은 잦은 문서 훼손이나, 편집 분쟁이 있을 때 관리자 판단하에 진행되며, 문의 게시판에 편집 권한 상향을 원하는 문서 제목과 사유를 올리면 관리자 확인 후 처리됩니다.

7.4. 어떤 대상에 대한 효빈위키 문서가 없습니다. [편집]

관심 있는 사용자가 적어서 아직 만들어지지 않은 경우, 다른 연관 문서에서 이미 설명되어 있으나 리다이렉트가 아직 생성되지 않은 경우, 등재 기준을 위반한 상태라 문서가 존재하지 않거나 삭제된 경우 등을 생각할 수 있습니다. 혹은 문서에서 다루는 주제의 당사자가 문서에 대한 임시조치를 요청하였을 특수한 경우도 존재합니다.[4]
특정 대상을 효빈위키에 등재하고자 할 경우 우선 등재 기준을 확인해보시고,
  • 별도의 등재 기준이 없거나, 등재 기준 충족 시: 새 문서 만들기를 참조하여 문서를 새로 만드셔도 좋습니다. 다만, 경우에 따라[5] 기존에 만들어져 있는 문서에 내용을 추가하신 후 문단 리다이렉트를 거는 방법이 좋을 수도 있습니다.
  • 등재 기준 미달 시: 규정 상 토론을 통해 3인 이상이 존치 합의를 내면 등재할 수 있다곤 하나 사실상 거의 불가능하며, 일반적으로 서술이 불가능합니다.

7.5. 효빈위키 문서를 인용하고 싶어요. [편집]

효빈일보, 효빈복지방송 등 일부 지역 언론에서는 효빈위키 내용을 그대로 캡처하여 기사에 사용하고 있으나, 이는 원칙상 본 위키의 라이선스인 CC BY-NC-SA 2.0 KR 중 BY(저작자 표기) 조항을 위반하는 것입니다. 따라서, 효빈위키의 라이선스상 인용 시 저작자를 표기해 두거나, 문서 역사를 링크하는 것이 좋습니다. 그러나 효빈위키의 라이선스는 NC(비영리) 조항에 따라 효빈위키에 기재된 문서 내용을 영리적으로 이용하는 것을 허가하고 있지 않습니다. 자세한 내용은 CC BY-NC-SA 2.0 KR 라이선스 정보를 참고해주시길 바랍니다.
라이선스 호환성 문제로 위키백과에 작성된 내용을 여기로 인용하는 것 및 그 반대 역시 허용되지 않습니다. FANDOM(위키아)의 내용을 인용하는 것 역시 본 위키가 사용하고 있는 라이선스와는 호환되지 않는 라이선스를 사용하는 관계로 서로 다른 두 위키의 라이선스에 저촉될 수 있습니다.
