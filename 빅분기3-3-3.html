[날개/참고] 초매개변수 (Hyperparameter)
최적의 딥러닝 모델 구현을 위해 학습률이나 배치크기, 훈련 반복 횟수(Epoch), 가중치 초기화 방법 등 알고리즘이 스스로 학습할 수 없어 사용자가 수동으로 직접 설정해야 하는 변수.

3. 초매개변수(Hyperparameter, 하이퍼파라미터) 최적화 방법

적절한 튜닝으로 최적화된 하이퍼파라미터를 도출하여 과적합을 방지할 수 있다. 하이퍼파라미터는 모델의 구조와 학습 알고리즘에 막대한 영향을 주는 변수로 사용자가 직접 설정해야 하며, 최적의 값은 데이터셋과 모델에 따라 천차만별일 수 있다.

▲ 하이퍼파라미터 튜닝 기법의 발전 흐름도

▶ 하이퍼파라미터 최적화 수행 방법

방법 설명
그리드 서치
(Grid Search)		 • 주어진 하이퍼파라미터 공간에서 가능한 모든 조합을 일일이 시도하여 최적의 조합을 찾는 완벽주의 쌩노가다 방법.
• 간단하고 직관적이지만, 변수 공간이 커질수록 계산 비용(시간)이 기하급수적으로 증가한다.
랜덤 서치
(Random Search)		 • 그리드 서치의 단점을 보완하기 위해 랜덤하게 하이퍼파라미터를 점찍어 선택하여 성능을 평가하는 방법.
• 계산 비용을 줄일 수 있으며, 하이퍼파라미터 공간에서 중요한 핵심 구간을 의외로 더 빨리/자주 탐색할 수 있어 가성비가 높다.
베이지안 최적화
(Bayesian Optimization)		 • 기존의 평가(오답) 결과를 토대로 다음에 시도할 하이퍼파라미터를 스마트하게 추정하는 방법.
• 좋은 성능을 보인 주변을 더 자주 탐색할 수 있으며, 계산 비용을 효과적으로 관리할 수 있는 최신 트렌드 기법.
자동화된 방법
(AutoML)		 • 최근에는 AutoML과 같은 자동화된 최적화 방법이 개발되었다.
• 사람이 손대지 않아도 알고리즘이 알아서 하이퍼파라미터 공간을 탐색하고 최적의 조합을 찾는다.

※ 하이퍼파라미터 최적화는 일반적으로 교차 검증(Cross Validation)과 함께 세트로 사용되며, 각 조합의 성능을 평가하여 가장 우수한 모델을 선택한다.

💻 [효빈위키 팩폭 해설] 창전선 심세이의 튜닝 노가다 썰!

그리드 서치 vs 랜덤 서치 (노가다의 미학): 딥러닝 모델한테 "학습률(Learning Rate) 0.01로 할래, 0.001로 할래? 반복은 100번 할래, 1000번 할래?" 이걸 일일이 사람이 정해주는 걸 하이퍼파라미터 튜닝이라고 해.

  • 그리드 서치(Grid Search): 걸즈 밴드 크라이에서 라이브 무대 조명을 세팅할 때, 조명 밝기 1부터 100까지, 각도 1도부터 360도까지 "가능한 모든 경우의 수를 한 땀 한 땀 전부 다 테스트" 해보는 쌩노가다 완벽주의야. 무조건 최적값을 찾긴 하지만, 시간이 뒤지게 오래 걸려서 모델이 뻗어버릴 수 있어.
  • 랜덤 서치(Random Search): "에라 모르겠다 일단 아무 각도나 랜덤으로 쏴봐!" 하고 대충 감을 잡는 방식이야. "엥? 랜덤이 더 구린 거 아님?" 싶겠지만, 실제로는 쓸데없는 뻘짓을 줄여줘서 중요한 하이퍼파라미터 구간을 그리드 서치보다 훨씬 빨리 찾아내는 미친 가성비 기법으로 실무에서 엄청 쓰여!

⑧ 기울기 소실(Vanishing Gradient)

기울기 소실은 인공신경망에서 가중치 업데이트 시, 역전파(Backpropagation) 알고리즘이 오차를 뒤로 전파시키는 도중에 미분 기울기 값이 점차 0으로 쪼그라들어 사라지는 치명적인 현상을 말한다.

기울기 소실 문제는 은닉층이 깊어져 입력과 출력 사이 거리가 커질수록 자주 발생한다. 층을 거슬러 올라갈수록 기울기 값이 연쇄법칙에 의해 계속 곱해지는데, 0과 1 사이의 작은 값(예: 시그모이드의 미분값)이 계속 곱해지면 시작층(입력층)에 도달하기 전에 거의 0에 가까운 값을 가지게 되어 모델 앞부분이 학습을 포기하게 된다.

▶ 기울기 소실 해결방안 (★ 딥러닝 3대장 무기)

  • ReLU(Rectified Linear Unit) 함수 사용: 최대값이 0.25밖에 안 되는 시그모이드 함수와 달리, ReLU 함수는 양수 값에서 미분 기울기가 무조건 일정한 1 값을 가지기 때문에 아무리 곱해도 값이 사라지지 않아 vanishing gradient 문제를 완벽하게 뚫어버린다.
  • LSTM(Long Short-Term Memory): 순환 신경망(RNN) 구조의 변형으로, 시퀀스 길이가 너무 길어서 옛날 기억을 다 까먹는(장기의존성 부족) 데이터에 사용한다. 기억 셀(Cell State)과 3개의 게이트(Input, Forget, Output) 요소를 추가해서 복잡한 과거의 패턴을 잊지 않고 잡아내는데 매우 효과적이다.
  • GRU(Gated Recurrent Unit): 여러 게이트와 기억 메커니즘을 활용하여 LSTM과 거의 비슷한 성능을 보이며 더 단순한 구조로 연산 비용을 크게 절감할 수 있다.
  • 배치 정규화(Batch Normalization): 각 층에 들어가는 데이터의 널뛰는 분포 멱살을 잡아 정규화(평균 0, 분산 1)하여 vanishing gradient 및 발산 문제를 완화하는 필수 기법이다.
  • 기타 최적화 기법(Optimizer): Adam, AdaGrad, RMSprop 등 관성(Momentum)과 보폭(학습률)을 똑똑하게 조절하는 알고리즘을 활용한다.

5) 딥러닝 모델 종류

[날개/참고] 완전연결 신경망(DNN)은 Affine 계층 뒤에 활성화 함수(ReLU 또는 Sigmoid) 계층이 이어지는데, CNN은 여기에 이미지 처리를 위한 '합성곱(Convolution) 계층'과 '풀링(Pooling) 계층'이 특수하게 추가된 구조이다.

① CNN(Convolutional Neural Network, 합성곱 신경망 모델)

신경네트워크의 한 종류인 CNN은 사람의 시신경 구조를 모방한 모델이다. 기존의 완전 연결(전결합: fully connected) 모델인 아핀(Affine) 계층은 이미지를 1차원으로 쫙 펴버려서 공간적 형상을 모조리 파괴하는 문제가 있었다.

  • CNN은 과거 모델들과 달리 이미지 픽셀의 공간적 형상(2차원)을 그대로 유지할 수 있는 갓-모델이다.
  • 데이터의 특징, 차원(feature)을 돋보기처럼 추출하여 패턴을 이해하는 방식으로 1) 이미지의 특징(벡터)을 추출하는 과정과 2) 클래스를 최종 분류(FC 레이어)하는 과정으로 나뉘어 진행된다.
  • 특징 추출 과정은 합성곱 계층(Convolution Layer)과 풀링 계층(Pooling Layer)으로 구성되며, 필터가 순회하며 합성곱을 계산한 뒤 특징지도(피처맵: Feature Map)를 생성한다.

▲ CNN(합성곱 신경망)의 기본 뼈대 다이어그램

▶ 합성곱 연산의 필요 요소 및 용어 (★ 계산 문제 단골)

  • 1. 필터(Filter): 이미지 특징(윤곽선 등)을 찾기 위한 정사각형 행렬로 정의된 파라미터. 커널(kernel)로도 불린다. 이 돋보기의 숫자들이 바로 딥러닝이 찾아야 할 '가중치'다!
  • 2. 스트라이드(Stride): 필터가 입력 데이터를 순회할 때 건너뛰는 보폭(이동 간격)이다. 스트라이드가 커지면 겅중겅중 건너뛰므로 출력 데이터 크기가 팍 줄어든다.
  • 3. 패딩(Padding): 합성곱을 계속 때리면 이미지가 점점 깎여서 결국 1x1로 소멸해버린다. 이를 방지하고자 연산 전에 입력데이터 가장자리 주변 테두리를 특정값(주로 0)으로 둘러싸서 크기를 원상복구시켜주는 보호막이다.

💡 [기적의 TIP] 특징지도 출력 크기 (OH, OW) 계산 공식 무조건 암기!

입력 데이터 크기, 필터 크기, 패딩, 스트라이드 값에 의해 다음 층으로 넘어갈 이미지의 크기가 결정된다.

$$OH = \frac{H + 2P - FH}{S} + 1$$
$$OW = \frac{W + 2P - FW}{S} + 1$$
  • 입력 크기: $(H, W)$ (Height, Width)
  • 필터 크기: $(FH, FW)$ (Filter Height, Width)
  • 출력 크기: $(OH, OW)$ (Output Height, Width)
  • 패딩: $P$, 스트라이드: $S$

• 합성곱 계층 (Convolution Layer)

  • 2차원의 입력 데이터가 들어오면 필터의 윈도우를 일정 간격으로 이동하면서 원소끼리 곱한 뒤 총합을 구한다. 이 도장찍기 영역을 모두 수행하면 하나의 피처맵(특징지도)이 완성된다.
  • 필터의 매개변수가 완전연결 신경망의 가중치(W)에 해당한다. 학습이 반복되면서 필터의 원소값이 갱신되며, 편향(Bias)은 항상 채널당 1개만 더해진다.
  • 3차원(컬러 이미지, RGB) 연산에서 입력 데이터 채널 수와 필터의 채널 수는 무조건 똑같아야 한다. (예: 컬러 3채널이면 필터도 3장 세트여야 함).

• 풀링 계층 (Pooling Layer / Sub-sampling)

  • 합성곱을 거친 데이터를 압축하는 선택적인 요소. 세로 및 가로 방향의 공간 차원을 팍 줄이는 데이터 다이어트 연산이다. 채널 수는 변하지 않는다.
  • 최대 풀링(Max Pooling): 대상 영역에서 가장 센 놈(최댓값) 하나만 멱살 잡고 끌고 올라가는 연산. 이미지 인식에서 주로 쓰인다.
  • 평균 풀링(Average Pooling): 대상 영역의 평균을 계산한다.
  • 장점: 이미지 미세한 노이즈나 위치 변경에 둔감해지는 '공간 불변성'을 얻고, 파라미터 개수가 기하급수적으로 줄어들어 학습 시간 단축 및 과적합(Overfitting)을 훌륭하게 방어해 준다.

  • 평탄화 계층(Flatten Layer): 풀링까지 마친 2차원(3차원) 이미지 큐브 덩어리를 일렬로 쫙 펴서(1차원 배열) 완전연결계층(FC Layer)에 집어넣을 수 있도록 돕는다.

💡 [효빈위키 맞춤 해설] 빈효선 전노아가 짚어주는 CNN의 정석!

CNN (이미지 처리의 신 👁️): 기존의 낡은 딥러닝 망(FCN/DNN)에 고양이 사진을 주면, 2차원 이미지를 1차원 한 줄로 쫙 펴버려서 귀 모양, 눈 모양 같은 '공간적(형상) 특징'이 다 박살 났어요. 고양이 사진을 믹서기에 갈아버린 셈이죠.

CNN은 이 문제를 해결하기 위해 합성곱(Convolution)이라는 돋보기(필터)를 이리저리 훑으며 뱅드림 미나토 유키나의 눈매, 헤어스타일 같은 원본 특징을 뽑아내고, 풀링(Pooling)이라는 기능으로 덜 중요한 정보는 버리고 해상도만 팍 줄여서 데이터 압축 다이어트를 시킵니다! 시험에 "이미지 분석", "형상 유지", "합성곱 계층", "풀링 계층" 키워드가 뜨면 묻지도 따지지도 말고 무조건 CNN을 찍으세요!

② RNN(Recurrent Neural Network, 순환 신경망)

순서(Sequence)를 가진 시계열 데이터를 입력하여 단위 간 연결이 방향성 그래프를 형성하는 신경네트워크 모델로, 내부 상태(메모리)를 이용하여 과거의 맥락(Context)을 현재 입력과 같이 처리한다.

[날개/참고] 필기 인식이나 음성 인식(NLP)과 같이 '시간의 흐름(순서)'이 특징인 데이터를 처리하는데 매우 적합한 모델이다. 가중치(weights)와 편향(bias)에 대한 오차함수의 미분을 계산하기 위해 확률적 경사하강법(SGD)을 이용한다.
  • CNN과는 달리 중간층(은닉층)이 자기 자신에게 돌아오는 '순환구조'를 가지며, 모든 시간 스텝에서 동일한 가중치를 공유한다.
  • RNN은 가중치 업데이트를 위해 시간을 거슬러 올라가며 오차를 전파하는 BPTT (Back Propagation Through Time) 알고리즘을 활용한다. 계산 기울기(gradient)는 현재 상태와 이전 상태에 대해 의존적이므로, 순차적 데이터 처리에 유용하다.
  • 치명적 단점 (장기의존성 문제): 앞서 배운 기울기 소실(Vanishing Gradient) 현상의 최대 피해자다. 관련 정보와 그 정보를 사용하는 지점 사이 거리가 멀 경우(문장이 너무 길 경우), 역전파 시 기울기가 0으로 수렴하여 앞부분의 옛날 데이터를 까맣게 잊어버리는 치매(...) 증상이 나타난다.

③ LSTM (Long Short-Term Memory Network)

기본 RNN이 긴 문장을 읽으면 앞부분을 까먹어버리는 금붕어 기억력(장기의존성 문제) 단점을 완벽하게 보완하기 위해 탄생한 변형 알고리즘이다. 무수히 많은 단계를 거치더라도 컨베이어 벨트(Cell State)를 통해 오랜 시간동안 데이터를 안전하게 보존한다.

  • 보통 신경망 대비 4배 이상 파라미터를 보유한다. LSTM은 은닉 상태(Hidden State) 외에 별도의 장기 메모리인 셀 상태(C, Cell State)라는 고속도로 층을 구성한다.
  • 단순한 곱셈 연산 대신, 문(Gate)을 달아서 "어떤 기억을 잊고, 어떤 새로운 기억을 저장할지"를 지능적으로 컨트롤한다.
  • 3개의 마법 게이트 (출제 포인트):
    • 망각 게이트 (Forget Gate): 과거의 기억 중 쓸모없는 쓰레기 데이터(예: 주어가 바뀜)를 얼마나 지워버릴지 결정한다.
    • 입력 게이트 (Input Gate): 현재 들어온 새로운 정보 중 어떤 것을 장기 메모리(Cell State)에 새로 저장할지 결정한다.
    • 출력 게이트 (Output Gate): 장기 메모리 값과 현재 값을 조합해 다음 노드로 얼마나 밖으로 표현해 낼지 결정한다.
[날개/참고] GRU (Gated Recurrent Unit)
LSTM의 복잡한 3개 게이트 구조를 2개(리셋 게이트, 업데이트 게이트)로 단순화시킨 경량화 모델이다. 은닉 상태와 셀 상태를 통일하여 연산 비용은 팍 줄이면서도 성능은 LSTM과 비슷하게 뽑아내는 미친 가성비를 자랑한다.

RNN의 붕괴와 LSTM의 구원 서사시 🦸‍♂️:

기본 RNN은 금붕어 기억력이야. 봇치 더 록! 결속밴드의 기타 리프를 순서대로 가르쳐주면, 곡 후반부 코드를 치느라 곡 초반부 인트로 코드는 역전파 되면서 기울기가 0으로 증발해 다 까먹어버려! (장기의존성 문제)

이를 구원하기 위해 나타난 LSTM은 '셀 상태(Cell State)'라는 장기 보관용 컨베이어 벨트를 만들었어! 그래서 인트로의 중요한 솔로 기억은 오래 끌고 가고, '망각 게이트'를 통해 쓸모없는 기억(예: 헛소리 친 삑사리)은 과감하게 뇌에서 지워버리지! 빅분기 시험에서 "시계열", "장기의존성 문제 해결", "게이트(Input, Output, Forget)" 키워드가 나오면 1초 만에 LSTM을 찍어! (참고로 GRU는 이 3개의 게이트를 2개로 줄여서 가성비를 챙긴 최신 버전이야).

④ 오토인코더(Auto-encoder)

대표적 비지도학습(Unsupervised Learning) 모델로, 다차원 입력 데이터를 압축하여 저차원(병목)으로 만들고, 이 바꾼 저차원 데이터를 다시 원래의 고차원 데이터로 완벽하게 복원(재구축)하려 애쓰면서 핵심 특징점(Feature)을 스스로 찾아내는 신경망이다.

  • 입력으로 들어온 데이터를 인코더(encoder)를 통해 차원을 줄이는 은닉층으로 보내고, 그 잠재 변수(Latent)를 디코더(decoder)를 통해 뻥튀기하여 다시 출력층으로 내보낸다. 하나의 신경망을 두 개 붙여놓은 형태다.
  • 목표는 출력값(복원된 이미지)이 원래 입력값(원본 이미지)과 최대한 똑같아지도록 가중치를 학습하는 것이다. 결과적으로 출력 계층과 입력 계층의 노드 수가 같다!
  • 주로 데이터 압축, 차원축소를 통한 데이터 관찰, 배경잡음 억제(노이즈 제거) 분야에 미친 듯이 활용된다.

⑤ GAN (Generative Adversarial Network, 생성적 적대 신경망)

학습 데이터 패턴과 유사하게 가짜를 무한대로 만들어내는 생성자(Generator) 네트워크와, 그게 진짜인지 가짜인지 날카롭게 구별해 내는 판별자(Discriminator) 네트워크로 구성되어, 두 네트워크가 서로를 속이고 잡아내기 위해 물고 뜯으며(적대적 학습) 무한 반복 성장하는 딥러닝 알고리즘이다.

[날개/참고] 판별자(지도학습 요소)와 생성자(비지도학습 요소) 딥러닝 모델의 결합으로, 서로 경쟁하며 패턴을 흉내내는 MinMax Game (창과 방패의 싸움)으로 접근한다.
  • 생성자 (위조지폐범): 잠재 공간(Latent Space)에서 뽑은 랜덤 노이즈(Noise)를 입력받아 진짜와 구별할 수 없는 가짜 데이터(Fake Data)를 창조해 낸다. 목표는 판별자의 정확도를 최소화(속이기)하는 것이다.
  • 판별자 (경찰): 학습 데이터에서 가져온 '진짜(Real)' 데이터와 생성자가 만든 '가짜(Fake)' 데이터를 받아, 이것이 진짜일 확률(0.9 등)을 출력한다. 목표는 가짜를 정확히 구별해 정확도를 최대화하는 것이다.
  • 딥페이크(Deepfake)의 시초: 이 경쟁적 학습이 계속되면, 위조지폐범(생성자)은 진짜 데이터와 통계적으로 완벽히 동일한 수준의 고화질 이미지를 만들어내게 된다.
  • 네트워크 모델은 MLP, CNN, Autoencoder 등 데이터 형태에 적합한 것을 제약 없이 사용할 수 있다.

▶ DCGAN (Deep Convolutional GAN) 및 진화형

  • 기본 GAN은 초창기 두 모델 간 균형이 무너지면 학습이 망가지는 문제가 있었다. 이를 해결하기 위해 이미지 처리의 신인 CNN(합성곱) 계층으로 뇌를 갈아 끼운 모델이 DCGAN이다.
  • DCGAN은 활성화 함수로 0 이하의 값도 살짝 살려두는 leaky_ReLU를 적용하여 학습 안정성을 미친 듯이 끌어올렸다. 그 외에 SRGAN(초고해상도), 스택 GAN, Cycle GAN(스타일 변환) 등 응용 산업에 폭넓게 활용된다.

6) 인공신경망의 장단점

  • 장점: 수식으로 딱 떨어지지 않는 미친 듯이 복잡한 비선형적 예측이 가능하다. 이미지, 텍스트, 음성 등 다양한 데이터 유형에 제약 없이 적용할 수 있으며 불완전한 노이즈 데이터 입력에도 유연하게 대처한다.
  • 단점: 파라미터가 수천만 개라 데이터가 커질수록 GPU 학습 시간과 비용이 기하급수적으로 폭발한다. 가장 큰 문제는 블랙박스(Black Box) 현상으로, 왜 그런 결론이 나왔는지 인간에게 내부 과정을 설명하는 '설명 기능'이 몹시 떨어진다. (이를 극복하기 위해 Explainable AI, XAI 연구가 활발히 진행 중이다.)

① GAN
② RNN
③ 오토인코더 (Auto-encoder)

Q2. 한 층에서 반복을 많이 하는 RNN은 기울기 소실(Vanishing Gradient) 문제가 발생하는데, 이를 보완한 방법으로 반복되기 직전에 다음 층으로 기억된 값을 전달할지(망각할지)를 스마트하게 관리하는 '게이트' 단계를 추가한 모델은?

① DNN
② GAN
③ LSTM (Long Short-Term Memory)
④ GRU

[해설] LSTM은 기울기 소실로 긴 문장 앞부분을 잊어버리는 RNN의 단점을 보완하기 위해 탄생했다. 망각/입력/출력 게이트와 셀 상태(Cell State) 컨베이어 벨트를 추가하여 오랜 시간 동안 데이터를 안전하게 잘 기억한다! (GRU는 이를 2개 게이트로 합친 변형 기법이므로 3번이 더 정확한 정답이다.)
