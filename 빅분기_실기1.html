1. 개요 (그리고 자주 하는 오해)

빅데이터분석기사(이하 빅분기) 실기 시험을 돌파하기 위해 반드시 몸에 익혀야 할 파이썬(Python) 기초 문법을 집대성한 문서이다. 필기시험을 61.25점 같은 짜릿한 점수로 턱걸이 합격했든 고득점으로 합격했든, 실기 시험장에서는 결국 손가락이 코드를 기억하느냐가 당락을 가른다. 이론만 백날 눈으로 읽으면 시험장에서 SyntaxError만 구경하다 나오기 십상이므로, 본 문서에는 러브라이브! 시리즈와 BanG Dream! 캐릭터들을 활용한 찰진 예제와 실제 브라우저에서 곧바로 코드를 고치고 돌려볼 수 있는 실습 에디터가 전 구간에 탑재되어 있다.

💡 Q: "선생님, 뒤에 ()가 붙어 있으면 전체 변수인가요?"

A: 절대 아닙니다! 괄호 ()는 "이름표가 붙은 도구(기계/함수)를 지금 당장 작동시켜라!"라는 실행 스위치입니다.
- print : 화면에 글자를 출력해주는 기계 자체의 이름.
- print("미나토 유키나") : 출력 기계 안에 "미나토 유키나"라는 재료를 집어넣고 작동 스위치 ()를 눌러서 화면에 보여주라는 뜻입니다.

판다스(pandas) 데이터프레임 만지다가 괄호 때문에 멘탈이 바사삭 부서져서 파이썬 기초부터 다시 보러 온 당신, 환영한다. 지금이라도 왔으니 절대 늦지 않았다.

2. 변수와 출력, 사칙연산

파이썬과 대화하는 가장 기본적인 방법은 값을 상자에 담고(변수), 계산하고(사칙연산), 화면에 보여주는(출력) 것이다.

  • print(...) — 화면에 보여줘!: 괄호 안에 있는 것을 화면에 보여 달라는 명령어다. 이때 화면에 튀어나온 글자를 출력이라고 부른다.
    • 글자 다루기 규칙: 파이썬에서 일반 글자(문자열)를 다룰 때는 반드시 앞뒤를 따옴표(" " 또는 ' ')로 감싸야 한다. 따옴표 없이 print(카스미)라고 적으면 파이썬은 '카스미'라는 이름의 변수를 찾다가 NameError를 뿜어낸다!
    • 쉼표(,)로 여러 개 출력하기: print(a, b)처럼 괄호 안에 쉼표로 여러 값을 나열하면, 한 줄에 알아서 띄어쓰기 한 칸을 사이에 넣어 나란히 붙여 보여준다.
  • 변수 (이름표): 어떤 값에 붙여주는 이름표다.
    • 예를 들어 character = "nakasu kasumi"라고 적으면, "nakasu kasumi"라는 문자열 값에 character라는 이름표를 딱 붙여두겠다는 뜻이다.
    • 이름표를 한 번 붙여두면, 그다음 줄부터는 긴 원래 값 대신 character라는 이름만 불러서 재사용할 수 있다. 매번 나카스 카스미 풀네임을 치다간 시험 시간 다 끝난다.
    • 변수 이름 짓기 규칙: 영어 알파벳, 숫자, 밑줄(_)로만 지을 수 있다. 단, 절대로 숫자로 시작할 수는 없다! (예: kasumi_1은 가능하지만, 1_kasumi나 공백이 들어간 nakasu kasumi는 문법 오류 발생).
  • = 와 == 의 결정적 차이 (시험 단골 함정):
    파이썬에서 등호 한 개(=)는 수학의 "같다"가 아니라 오른쪽 값을 왼쪽 이름표 상자에 "담아라(대입해라)"라는 화살표(⬅️) 명령이다.
    양쪽 값이 진짜로 똑같은지 비교할 때는 등호를 두 개 연달아 쓴 == 기호를 사용해야 한다.
  • 파이썬 사칙연산과 반올림:
    • 기본 연산: +(더하기), -(빼기), *(곱하기), /(소수점 끝까지 나누기).
    • 특수 나눗셈: 몫만 깔끔하게 필요하면 //를 쓰고, 나누고 남은 나머지만 필요하면 %를 쓴다. 야마부키 베이커리에서 초코소라빵 10개를 사아야, 모카, 리미 3명에게 똑같이 나눠주면 1인당 몫(10 // 3)은 3개고, 남는 빵(10 % 3)은 1개인데 그건 모카 뱃속으로 들어간다.
    • round(값, 자리수): 소수점 아래 몇째 자리까지 반올림해서 남길지 지정한다. (주의: 파이썬은 대소문자를 칼같이 구분하므로 대문자 Round가 아니라 반드시 소문자 round로 적어야 한다!)
    • 띄어쓰기 무관 법칙: 숫자나 연산 기호 사이의 띄어쓰기는 계산 결과에 아무런 영향을 주지 않는다. 즉, 43000+7이나 43000 + 7이나 완전히 똑같은 값(43007)이다.

3. 문자열 (String) 다루기

따옴표로 감싼 글자를 전문 용어로 문자열(String, 줄여서 str)이라고 부른다. 파이썬의 문자열에는 자기 자신을 손질하고 변형하는 똑똑한 기능(메서드)들이 기본 장착되어 있으며, 언제나 값.기능() 또는 변수.기능() 모양으로 호출한다.

  • len(값): 전체 길이를 센다. 문자열을 넣으면 총 글자 수를 알려준다. 주의: 눈에 안 보이는 띄어쓰기(공백)도 엄연한 한 글자로 취급한다!
  • .strip(): 문자열 양 끝(앞뒤)에 붙은 쓸데없는 공백이나 줄바꿈을 깔끔하게 면도하듯 제거한다. (단, 글자와 글자 한가운데에 끼어 있는 띄어쓰기는 건드리지 않는다).
  • .upper() / .lower(): 모든 알파벳 문자를 대문자(UPPER) / 소문자(lower)로 일괄 변환한다. (예: "Roselia".upper() ➡️ "ROSELIA").
  • .split(" "): 괄호 안에 지정한 글자(여기서는 띄어쓰기 " ")를 기준으로 문자열을 싹둑 잘라 여러 조각이 담긴 리스트로 만든다.
    • 잘라낸 조각들은 앞에서부터 차례대로 [0], [1], [2]... 번호표를 달고 꺼낼 수 있다.
    • 실전 팁: 앞뒤 공백이 더럽게 섞인 문자열에서 첫 단어를 꺼낼 때는 먼저 clean = raw.strip()으로 공백을 닦아낸 뒤, clean.split(" ")[0]으로 첫 조각을 꺼내야 빈칸이 튀어나오는 대참사를 막을 수 있다!
  • f"..." (f-string, 빅분기 최고 존엄 문법): 따옴표 바로 앞에 알파벳 f를 붙이면, 문자열 안의 중괄호 {변수} 자리가 그 변수의 실제 값으로 뿅 하고 바뀐다. 숫자와 글자를 억지로 더하다가 에러 내지 말고, 이어 붙일 때는 무조건 f-string을 쓰자!

4. 리스트 (List)와 인덱스

리스트는 여러 개의 값을 순서대로 줄 세워 담는 기차 칸 같은 상자다. 만들 때는 대괄호 [ ]로 감싸고 쉼표로 값을 구분한다: 예) [79, 89, 99].

  • 인덱스 (자리번호): 리스트 안의 각 칸에 붙은 번호표다. 파이썬은 무조건 0부터 숫자를 센다!
    • 앞에서부터 셀 때: 첫 번째는 [0], 두 번째는 [1], 세 번째는 [2]...
    • 뒤에서부터 거꾸로 셀 때: 맨 마지막 값은 [-1], 뒤에서 두 번째 값은 [-2]다. 데이터 개수가 몇만 개든 맨 끝 값은 언제나 [-1] 하나로 해결된다!
  • 슬라이싱 (구간 잘라오기): [1:3]처럼 콜론(:)으로 범위를 적으면 1번 자리부터 3번 자리 직전(즉, 2번 자리)까지만 잘라온다. 끝 번호는 절대 포함하지 않는다! (실기 시험 오답률 1위 구간)
  • 리스트 내장 계산 도구들:
    • len(리스트) : 담긴 값의 총 개수
    • sum(리스트) : 담긴 숫자들의 전체 합계
    • max(리스트) / min(리스트) : 최댓값 / 최솟값
    • 평균 구하기: 기본 파이썬에는 리스트 평균을 바로 구하는 avg() 같은 내장 함수가 없다! 따라서 평균은 무조건 sum(리스트) / len(리스트)로 직접 나눠서 구한다.
    • sorted(리스트): 작은 값부터 큰 값 순서(오름차순)로 가지런히 정렬한 새 리스트를 돌려준다. 따라서 "두 번째로 큰 값"을 찾으라는 문제가 나오면 sorted(리스트)[-2]로 한 줄 컷할 수 있다!

4.1. [직접 해보기 1] 점수 리스트 7종 세트

🎯 실습 과제: scores = [72, 88, 95, 61, 80] (니지가사키 멤버 5인의 보컬 테스트 점수)으로 ① 첫 값 ② 마지막 값 ③ [1:3] 조각 ④ 개수 ⑤ 합 ⑥ 평균(소수 둘째 자리) ⑦ 두 번째로 큰 값을 차례대로 출력하세요.
[직접 해보기 1] 내 코드 실행기

💡 막혔을 때 힌트 & 표준 풀이와 비교하기 (클릭해서 펼치기)

• 힌트 1: 마지막 값은 scores[-1] 입니다. 개수를 직접 세서 scores[4]라고 적어도 지금은 맞지만, 나중에 데이터 개수가 바뀌면 틀리게 됩니다.

• 힌트 2: scores[1:3]은 1번 자리(88)와 2번 자리(95), 딱 두 개만 나옵니다. 끝 번호인 3번 자리(61)는 포함되지 않습니다!

• 힌트 3: 두 번째로 큰 값은 sorted(scores)[-2] 입니다. 오름차순 정렬([61, 72, 80, 88, 95])의 뒤에서 두 번째가 곧 두 번째로 큰 값(88)입니다.

5. 딕셔너리 (Dictionary)

리스트가 0번, 1번 같은 '자리 번호'로 값을 관리한다면, 딕셔너리(Dictionary, 사전)는 자리 번호 대신 이름(키, Key)으로 짝꿍 값(Value)을 꺼내는 상자다. 중괄호 { }로 적으며, "키": 값 형태로 짝을 짓는다: 예) {"이름": "사쿠라우치 리코", "점수": 88}.

  • 값 꺼내기: info["이름"]처럼 대괄호 안에 키 이름을 정확히 적는다. 리스트의 [0] 자리에 숫자 대신 이름표가 들어간다고 보면 이해하기 쉽다.
  • 값 추가와 수정 (덮어쓰기):
    • 딕셔너리에 없는 키에 값을 대입하면 새로운 짝이 추가된다: info["악기"] = "피아노"
    • 이미 있는 키에 값을 대입하면 기존 값을 지우고 새 값으로 덮어쓴다: info["점수"] = 92 한 줄로 수정이 깔끔하게 끝난다!
  • 목록 확인하기와 개수 세기:
    • .keys()는 키(이름표)들만, .values()는 값들만 모아 준다. 단, 그대로 출력하면 dict_keys([...])처럼 낯선 모양으로 나오니, 눈으로 보기 편하게 list(info.keys())처럼 list(...)로 감싸 리스트로 바꿔 확인한다.
    • 딕셔너리에 들어 있는 '키:값' 짝(쌍)의 총 개수도 리스트와 똑같이 len(딕셔너리)로 구한다.
  • 왜 빅분기에서 중요한가?: 바로 다음 단원인 pandas에서 데이터프레임의 열 이름을 바꿀 때(df.rename(columns={"옛이름": "새이름"})), 혹은 그룹별로 서로 다른 통계 계산을 시킬 때(df.groupby(...).agg({"매출": "sum", "평점": "mean"})) 이 중괄호 딕셔너리 모양이 토씨 하나 안 바뀌고 그대로 등장한다! 지금 눈에 익혀 두면 판다스가 열 배는 편해진다.

6. 조건문(if)과 반복문(for)

⚠️ 파이썬에서 들여쓰기(보통 띄어쓰기 4칸 또는 Tab 1번)는 보기 좋으라고 멋으로 넣는 장식이 아니라 문법 그 자체다! 들여쓰기 줄을 맞추지 않으면 값이 엉뚱하게 꼬이거나 IndentationError가 터지므로 목숨 걸고 확인해야 한다.
  • 조건문 (if / elif / else):
    • if 조건: 아래에 4칸 들여쓴 줄들은 조건이 참(True)일 때만 실행된다. (주의: 조건문과 반복문 줄 맨 끝에는 반드시 콜론 :을 찍어야 한다!)
    • 조건이 틀렸을 때 다른 일을 시키려면 else:, 조건을 여러 단계로 늘어놓으려면 elif 조건:을 쓴다. 위에서부터 차례대로 검사하다가 가장 먼저 맞는 것 딱 하나만 실행하고 조건문을 빠져나간다.
  • 비교 연산자와 논리 연산자:
    • 비교 기호: ==(같다), !=(다르다), >(크다), <(작다), >=(크거나 같다), <=(작거나 같다). 상자에 값을 담는 =와 비교하는 ==를 헷갈리면 100% 문법 오류가 난다.
    • 비교의 결과 자체가 값(Boolean)이다! 예를 들어 score >= 60을 계산하면 그 결과로 True 또는 False라는 논리값이 튀어나온다. 이 값을 그대로 print()로 찍어볼 수도 있고, 나중에 pandas에서는 이 True/False 묶음(불리언 인덱싱)이 원하는 조건의 행(Row)만 쏙 골라내는 핵심 필터 도구가 된다!
    • 조건 묶기: and는 양쪽 조건이 둘 다 맞아야 참, or는 둘 중 하나만 맞아도 참, not은 참/거짓을 반대로 뒤집는다.
  • 반복문 (for)과 누적 패턴:
    • for 이름 in 리스트:는 리스트에서 값을 앞에서부터 하나씩 꺼내 이름 변수에 담아 가며 아래 들여쓴 줄들을 끝까지 반복 실행한다.
    • range(3): 0, 1, 2를 순서대로 만들어낸다. 리스트 슬라이싱과 똑같은 규칙으로 끝 숫자(3)는 포함하지 않는다!
    • 누적(Accumulation)의 대원칙: 합계를 구하거나(total = total + c) 조건에 맞는 개수를 셀 때(big = big + 1), 값을 모아 담을 빈 그릇(total = 0, big = 0)은 반드시 for 반복문 바깥(위쪽)에서 먼저 만들어 두어야 한다! 만약 그릇을 반복문 안에서 만들면, 한 바퀴 돌 때마다 그릇이 0으로 리셋되어 맨 마지막 값만 남는 대참사가 벌어진다. 나카스 카스미가 쿠페빵 도장을 찍어주는데 매일 아침 도장 카드를 새로 사서 찍는 격이다.
    • 판다스와의 연결고리: 나중에 pandas를 배우면 이런 반복문 대부분을 df['컬럼'].sum() 같은 한 줄로 대체하게 된다. 하지만 이 for 반복과 누적의 원리를 알고 있어야 판다스의 그 한 줄이 내부적으로 무슨 짓을 하는지 정확히 읽을 수 있다!

7. 함수: return vs print

함수(Function)는 자주 쓰는 계산 과정에 이름을 붙여 둔 '자동화 자판기'다. def 이름(재료): 형태로 만들며, 그 아래 4칸 들여쓴 줄들이 자판기 내부의 작동 내용이 된다. 사실 우리가 지금까지 신나게 썼던 sum, len, round, print도 전부 파이썬 제작자들이 미리 만들어 둔 함수다!

🚨 기억할 단 한 가지 (초보가 가장 많이 빠지는 함정):
return 값은 계산 결과를 함수 바깥으로 진짜로 돌려준다(배출한다). 반면 print는 화면에 글자를 잠깐 보여 줄 뿐 아무 값도 돌려주지 않는다! 만약 함수 끝에서 return을 빼먹으면 함수를 열심히 불러도 텅 빈 값인 None이 튀어나온다.
야마부키 베이커리에서 사아야가 빵을 구워서 손님 손에 쥐여주려면 return 빵을 해야 한다. 함수 안에 print(빵)만 적어놓는 건 유리 진열장 너머로 빵을 자랑만 하고 손님에겐 빈 봉투(None)를 건네는 악질 기만 행위다!
  • 매개변수(Parameter)와 인자(Argument): 함수를 정의할 때 괄호 안에 적는 빈칸 이름을 매개변수라고 하고(예: def average(values):의 values), 실제로 함수를 호출할 때 집어넣는 진짜 데이터 값을 인자라고 부른다(예: average([70, 85, 90])에서 리스트 [70, 85, 90]).
  • 기본값(Default) 지정하기: def tax(price, rate=0.1):처럼 매개변수에 =로 기본값을 미리 세팅해 둘 수 있다. 함수를 부를 때 두 번째 값을 생략하고 tax(24000)만 부르면 기본값인 0.1이 자동으로 쓰이고, tax(24000, 0.2)처럼 새 값을 주면 준 값(0.2)이 우선 적용된다!

8. 모듈(import)과 오류 대처 (형변환)

파이썬에는 전 세계 천재들이 미리 만들어 둔 고급 도구 묶음이 엄청나게 많다. 이 묶음을 모듈(Module) 또는 패키지(Package)라고 부르며, 내 코드에서 쓰려면 맨 위에서 import 명령어로 소환해야 한다.

  • 모듈을 불러오는 3가지 문법 (비교 필수!):
    1. import math (통째로 가져오기): math 도구 상자 전체를 가져온다. 안에 든 기능을 쓸 때는 math.sqrt(144)나 math.pi처럼 상자 이름을 앞에 꼭 붙여야 한다.
    2. from statistics import mean (지 혼자 가져온 놈!): statistics 상자 안에서 평균 구하는 mean 도구 딱 하나만 쏙 꺼내 온다. 이때는 지 혼자 빠져나왔으므로 앞에 상자 이름을 붙이지 않고 그냥 mean([2, 4, 9])처럼 이름만 바로 쓴다! (실기 시험에서 from sklearn.ensemble import RandomForestClassifier 할 때 매일 쓰는 방식이다).
    3. import pandas as pd (별명 붙이기): 상자를 가져오면서 pd라는 짧은 별명(Alias)을 붙인다. pandas를 pd, numpy를 np로 부르는 것은 전 세계 데이터 분석가들의 절대 관행이다. (참고로 별명 뒤에 pd.__name__처럼 앞뒤 밑줄 2개짜리 속성을 찍어보면 원래 본명인 'pandas'를 알려준다).
  • 빅분기 실기 시험장 패키지 규칙: 시험장 컴퓨터는 외부 인터넷이 차단되어 있어 pip install로 패키지를 새로 설치할 수 없다! 오직 이미 깔려 있는 패키지(numpy · pandas · scipy · scikit-learn · statsmodels 등)만 import해서 풀어야 한다.
  • 오류(Error)는 실패가 아니라 가장 정확한 내비게이션 안내문이다:
    • 오류 메시지가 영어 줄글로 길게 떠도 당황하지 말고 맨 마지막 한 줄만 읽어라! 거기에 원인과 해결책이 다 적혀 있다.
    • 자주 만나는 에러 3대장:
      ① NameError : 없는 변수나 함수 이름을 썼다 (99% 확률로 철자 오타이거나, import를 안 했거나, 위에서 변수를 아직 안 만들었다).
      ② TypeError : 자료형(Type)이 서로 안 맞는다 (예: unsupported operand type(s) for +: 'int' and 'str' ➡️ "정수와 문자열은 더할 수 없다!").
      ③ IndentationError / SyntaxError : 들여쓰기 칸수가 어긋났거나, 조건문 끝에 콜론(:), 혹은 닫는 괄호 )를 빼먹었다.
  • 자료형 확인(type)과 형변환(Casting):
    • 겉보기에 똑같이 3처럼 생겼어도 따옴표가 붙은 "3"은 글자(str)이고, 따옴표가 없는 3은 숫자(int)다. 정체가 헷갈릴 땐 type(값)으로 찍어보면 <class 'str'>인지 <class 'int'>인지 바로 자백한다.
    • 실기에서 CSV 데이터 파일을 읽어오면 숫자가 글자로 둔갑해 들어와 있는 경우가 허다하므로, 다음 형변환 함수 3총사를 숨 쉬듯 써야 한다:
      • 글자 ➡️ 정수로: int("3")
      • 글자 ➡️ 소수로: float("3.5")
      • 숫자 ➡️ 글자로: str(3)
