1. 개요 (그리고 오해)

빅데이터분석기사(이하 빅분기) 실기 시험을 위해 반드시 숙지해야 할 파이썬(Python) 기초 문법을 정리한 문서이다. 이론만 백날 읽는 것보다 직접 쳐보는 것이 중요하므로, 본 문서에는 애니메이션(러브라이브, 뱅드림 등) 캐릭터를 활용한 찰진 예제와 실제 브라우저에서 파이썬 코드를 돌려볼 수 있는 실습 에디터가 탑재되어 있다.

💡 Q: "()이면 전체 변수인가요?"

A: 아닙니다! 괄호 ()는 "이름표가 붙은 도구(기계)를 지금 당장 작동시켜라!"라는 실행 버튼입니다.
- print: 출력하는 도구 자체의 이름.
- print("유키나"): 출력 도구 안에 유키나를 넣고 작동(실행)시켜서 화면에 보여주라는 뜻입니다.

판다스(pandas) 하다가 데이터프레임에서 빡쳐서 파이썬 기초부터 다시 보러 온 당신, 환영한다. 늦지 않았다.

2. 변수와 출력, 사칙연산

  • print(...): 괄호 안에 있는 것을 화면에 보여주는 도구. 화면에 나온 글자를 출력이라고 한다. print(a, b)처럼 쉼표(,)로 여러 개를 주면 한 줄에 띄어쓰기로 붙여서 보여준다.
  • 변수 (이름표): 값에 붙이는 이름표. 영문 알파벳, 숫자, 밑줄(_)로 짓지만 숫자로 시작할 수는 없다.
  • = 와 == 의 차이 (매우 중요):
    =는 "같다"가 아니라 오른쪽 값을 왼쪽 이름표 상자에 "담아라"는 뜻이다.
    == 기호가 진짜로 양쪽이 같은지 비교하는 기호다.
  • 사칙연산: +, -, *(곱하기), /(소수까지 나누기), //(몫만), %(나머지만).
    round(값, 자리수)를 쓰면 소수점 아래 몇 자리까지 남길지 지정할 수 있다.

3. 문자열 (String) 다루기

따옴표로 감싼 글자를 '문자열'이라고 한다. 문자열에는 자기 자신을 변형하는 유용한 기능들이 내장되어 있으며, 값.기능() 모양으로 부른다.

  • len(값): 길이를 센다. 문자열을 넣으면 글자 수를 센다. (공백도 한 글자로 취급!)
  • .strip(): 양 끝의 쓸데없는 공백을 제거한다.
  • .upper() / .lower(): 모든 문자를 대문자 / 소문자로 바꾼다.
  • .split(" "): 띄어쓰기(또는 지정한 글자)를 기준으로 잘라서 여러 조각의 리스트로 만든다. 첫 조각은 뒤에 [0]을 붙여 꺼낸다.
  • f-string (핵심): 따옴표 앞에 f를 붙이면 f"..." 안의 {변수}가 그 변수의 실제 값으로 바뀐다. 숫자와 글자를 섞어 출력할 때 빅분기에서 가장 많이 쓴다.

4. 리스트 (List)와 인덱스

리스트는 값 여러 개를 순서대로 담는 상자로, 대괄호 []를 사용한다.

  • 인덱스 (자리번호): 파이썬은 0부터 센다. 첫 번째는 [0], 두 번째는 [1]이다. 맨 뒤는 [-1], 뒤에서 두 번째는 [-2]다.
  • 슬라이싱 (자르기): [1:3]처럼 적으면 1번 자리부터 3번 자리 직전(2번)까지만 잘라온다. 끝 번호는 포함 안 함을 명심하자! (시험에서 제일 많이 틀림)
  • 슬라이싱 응용 (생략하기): 시작이나 끝 번호를 비워두면 전체를 가져올 수 있다. scores[:]는 처음부터 끝까지(전체) 가져온다. scores[2:]는 2번부터 끝까지, scores[:3]은 처음부터 3번 직전(2번)까지라는 뜻이다.
  • 리스트 도구들: len()은 개수, sum()은 합, max()/min()은 최대/최소를 바로 구해준다. 평균은 sum(리스트) / len(리스트)로 직접 계산해야 한다.
  • sorted(리스트): 작은 것에서 큰 것(오름차순)으로 정렬된 새 리스트를 준다. 두 번째로 큰 값을 찾고 싶으면 정렬 후 [-2]로 꺼낸다.

5. 딕셔너리 (Dictionary)

자리 번호(0, 1...) 대신 이름(키)으로 값을 꺼내는 상자다. 중괄호 {}로 적는다.

  • 꺼낼 때는 리스트처럼 대괄호를 쓰되, 안에 숫자가 아닌 키를 적는다: info["이름"]
  • 없는 키에 값을 넣으면 새로 추가되고, 있는 키에 넣으면 덮어쓴다. (info["점수"] = 92 한 줄로 수정 끝)
  • .keys()는 키들만, .values()는 값들만 준다. 보기 편하게 list(...)로 감싸서 확인한다.
  • 이 딕셔너리 모양 {"A": "B"}는 나중에 Pandas에서 열 이름을 바꾸거나(rename), 그룹별 계산을 시킬 때(agg) 그대로 등장하므로 눈에 익혀두어야 한다.

6. 조건문(if)과 반복문(for)

파이썬에서는 들여쓰기(스페이스 4칸)가 문법 그 자체다. 멋으로 넣는 것이 아니며, 틀리면 IndentationError가 발생한다. 제발 탭과 스페이스를 섞어 쓰지 마라.

  • 조건문: if 조건: 아래에 들여쓴 줄은 조건이 맞을 때만 실행된다. 아니면 elif 조건:, 다 틀리면 else:로 간다.
  • 비교 기호: ==(같다) !=(다르다) > < >= <=. 담을 때 쓰는 =와 헷갈리면 안 된다!
  • 비교의 결과 자체가 값(True/False)이다. and(둘다), or(하나만), not(뒤집기)으로 조건을 묶을 수 있다.
  • 반복문: for 이름 in 리스트: 리스트 값을 하나씩 꺼내 '이름'에 담아가며 아래 들여쓴 줄을 반복한다.
  • range(3)은 0, 1, 2를 만든다 (끝 숫자 포함 안 함).
  • 누적의 함정: 누적 그릇(total = 0, count = 0)은 반드시 반복문 밖에서 만들어야 한다. 안에서 만들면 매번 0으로 비워져서 마지막 값만 남는 대참사가 일어난다.

7. 함수: return vs print

함수는 이름을 붙여 둔 계산 묶음이다. def 이름(재료_매개변수): 로 만든다.

🚨 초보가 가장 자주 만나는 함정!
return이 없으면 함수는 아무것도 돌려주지 않는다 (None이 나옴).
print는 화면에 보여줄 뿐이다. 빵을 구워서 남에게 주려면 return을 해라. print는 유리창 너머로 빵을 보여주기만 하고 안 주는 악질 행위다.
  • def tax(price, rate=0.1): 처럼 기본값을 줄 수 있다. 부를 때 안 주면 0.1이 쓰인다.
  • 사실 우리가 쓰던 sum, len, round 도 전부 파이썬에 이미 만들어진 함수다.

8. 모듈과 오류 대처 (형변환)

  • 모듈 가져오기: 파이썬 도구 상자다. 시험장에서는 이미 깔린 것만 import 할 수 있다.
    • import math: 상자 전체 가져오기. 쓸 땐 math.sqrt()
    • from statistics import mean: 상자 안에서 하나만 쏙 빼오기 (지 혼자 가져온 놈). 상자 이름 없이 mean() 이름만 쓴다.
    • import pandas as pd: 상자를 가져오면서 pd라는 짧은 별명을 붙인다.
  • 오류는 정확한 안내문이다: 겁먹지 말고 맨 아랫줄을 보자.
    TypeError: unsupported operand type(s) for +: 'int' and 'str'
    ➡️ "정수(int)와 문자열(str)을 더할 수 없다"는 뜻이다.
  • 형변환: CSV 파일을 읽으면 숫자가 글자로 들어오는 경우가 흔하다. 겉보기가 같아도 3(숫자)과 "3"(글자)은 다르다. 값이 뭔지 모르겠으면 type(값)으로 확인한다.
    • 글자 ➡️ 숫자로: int("3") 또는 float("3.5")
    • 숫자 ➡️ 글자로: str(3)
