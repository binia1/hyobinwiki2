1. 가설·유의수준·p-value의 진실 ("귀무가설 채택" 절대 금지!)

👑 나카스 카스미 (1학년 후배 수강생): "아유무 선배! 에리 선배님! 문제에서 p-value가 0.0826이 나와서 유의수준 0.05보다 크길래, 카스밍이 당당하게 '귀무가설을 채택한다!'라고 적었거든요? 그랬더니 왜 오답 처리가 된 거예요?! 기각 안 하면 채택하는 거 아니에요?!"

🎀 우에하라 아유무 (2학년 선배 강사): "카스미 쨩, 통계학 법정에서는 '귀무가설을 채택한다'는 말은 절대 쓰면 안 되는 금기어야! p >= 0.05가 나온 건 '차이가 있다고 우길 만한 증거가 부족하다(무죄 추정)'는 뜻이지, '두 값이 100% 똑같다는 게 증명됐다!'는 뜻이 아니거든. 그래서 무조건 '귀무가설을 기각하지 못한다'(또는 대립가설을 기각한다)라고 적어야 해!"

  • 귀무가설($H_0$) vs 대립가설($H_1$):
    • 귀무가설($H_0$): "차이가 없다 · 효과가 없다 · 서로 독립이다(관련 없다) · 계수가 0이다"라는 보수적인 기본 입장. 모든 통계 검정은 언제나 귀무가설이 참이라는 가정하에 계산을 시작한다.
    • 대립가설($H_1$): 우리가 입증하고 싶은 새로운 주장 ("차이가 있다 · 효과가 있다 · 관련이 있다").
  • 유의수준($\alpha$)과 p-value 판정 공식:
    • p-value(유의확률)의 정의: "귀무가설이 맞다고 쳤을 때, 지금 내 눈앞에 나온 표본 결과만큼(또는 그보다 더) 극단적인 일이 순전히 우연으로 벌어질 확률"이다.
    • ✅ p < 0.05 (유의수준 $\alpha=0.05$ 미만): "우연히 일어날 확률이 5%도 안 된다고? 이건 우연이 아니라 진짜 차이가 있는 거다!" ➡️ 귀무가설($H_0$)을 기각한다 (대립가설 채택).
    • ❌ p >= 0.05 (유의수준 $\alpha=0.05$ 이상): "음, 8.26% 확률이면 우연히 그럴 수도 있겠네. 귀무가설을 깨부술 증거가 부족하다." ➡️ 귀무가설($H_0$)을 기각하지 못한다.

2. 일표본 t-검정: 양측검정 vs 단측검정 (alternative와 절반의 법칙)

💧 오사카 시즈쿠 (1학년 후배 수강생): "쿠쿠 선배님! 일표본 t-검정을 할 때 어떨 때는 그냥 stats.ttest_1samp(chol, 190)만 쓰고, 어떨 때는 뒤에 alternative='greater'나 'less'를 붙이잖아요! 언제 뭘 써야 하고, 왜 greater의 p-value가 양측의 딱 절반(1/2)이 되는 건가요?"

🍨 탕 쿠쿠 (일타 강사): "시즈쿠! 방향은 우리가 고르는 게 아니라 문제지 발문이 시키는 대로 고르는 거예요 데스! 발문에 '190과 다른지'라고 적혀 있으면 양쪽 다 보는 양측검정(기본값)이고, '190보다 큰지(greater)' 또는 '작은지(less)'라고 방향을 콕 집어 말하면 한쪽 꼬리만 재는 단측검정이에요!"

  • 양측검정 vs 단측검정 옵션 (alternative):
    • alternative="two-sided" (기본값, 생략 가능): 평균이 기준값과 다른지($\mu \neq 190$) 검정.
    • alternative="greater": 평균이 기준값보다 큰지($\mu > 190$) 검정.
    • alternative="less": 평균이 기준값보다 작은지($\mu < 190$) 검정.
  • ★ 마법의 절반(1/2) 법칙:
    health.csv의 실제 콜레스테롤 평균은 196.7727로 기준값 190보다 크다. 따라서 검정통계량도 양수(+3.6675)가 나온다.
    이처럼 표본이 실제로 190보다 큰 상태에서 "190보다 큰가(greater)?"를 물으면, 한쪽 꼬리 넓이만 재므로 양측 p-value(0.00034...)의 정확히 절반인 0.00017...(반올림 시 0.0002)이 나온다! 반면 엉뚱한 반대 방향인 less("190보다 작은가?")의 p-value는 $1 - 0.00017 = 0.9998$이 되어 둘을 더하면 정확히 1.0이 된다!

🌸 오토무네 코즈에 (기계치 수강생): "히메야… '성별과 운동 여부가 서로 관련이 있는지' 알아보는 카이제곱 검정을 하려고 stats.chi2_contingency(df['성별'], df['운동'])을 넣었더니 또 컴퓨터가 에러를 내며 멈췄어…"

🎮 안요지 히메 (일타 강사): "코즈에 선배! 카이제곱 기계(chi2_contingency)에는 원본 글자 열을 날것으로 넣으면 탈이 나요! 무조건 table = pd.crosstab(df['성별'], df['운동'])으로 네모난 빈도 교차표를 먼저 만든 다음, 그 table을 통째로 던져 넣어야 작동해요!"

  • 카이제곱 독립성 검정의 가설:
    • 귀무가설($H_0$): 두 범주형 변수는 서로 독립이다 (아무 관련이 없다).

4. 일원배치 분산분석(ANOVA): 그룹이 3개 이상일 때 (*groups 별표 언패킹)

👑 나카스 카스미 (1학년 후배): "아이 선배! 식단이 A, B, C 세 종류일 때 콜레스테롤 평균을 비교하려면, 그냥 A랑 B t-검정하고, B랑 C t-검정하고, A랑 C t-검정해서 세 번 하면 안 돼요? 왜 굳이 f_oneway라는 새로운 함수를 외워야 해요?!"

🧡 미야시타 아이 (2학년 선배 강사): "카스미! t-검정을 여러 번 반복하면 1종 오류(사실은 차이가 없는데 우연히 차이가 있다고 잘못 판정할 확률)가 눈덩이처럼 불어나거든! 그래서 집단이 3개 이상일 땐 한 방에 비교하는 일원배치 분산분석(One-way ANOVA, stats.f_oneway)을 써야 해! 그리고 기각하더라도 '적어도 한 집단의 평균은 다르다'까지만 말할 수 있어!"

  • stats.f_oneway(그룹1, 그룹2, 그룹3)와 별표(*) 언패킹의 마법:
    리스트 컴프리헨션 groups = [g["콜레스테롤"].values for _, g in df.groupby("식단")]으로 집단별 배열을 묶었을 때, 함수에 넣을 때는 반드시 앞에 별표(*)를 붙여 stats.f_oneway(*groups)로 껍질을 까서 넘겨야 한다! 별표 없이 f_oneway(groups)라고 넣으면 리스트 1개만 넘긴 꼴이 되어 즉시 에러가 난다!

5. 다중 선형 회귀(OLS): 계수(.params), p-value, 결정계수(R²)

  • 수식(Formula) 기반 선형 회귀: from statsmodels.formula.api import ols를 불러와 model = ols("종속변수 ~ 독립1 + 독립2", data=df).fit() 한 줄이면 회귀식이 완성된다! (물결표 ~ 왼쪽이 맞출 타깃, 오른쪽이 설명변수들이며 상수항 Intercept가 자동으로 포함된다. 끝에 .fit()을 빼먹지 말자!).
  • 시험에서 묻는 3대 속성:
    1. model.params (회귀계수): 각 독립변수가 1단위 증가할 때(다른 변수가 고정된 상태에서) 종속변수가 평균적으로 얼마나 변하는지 나타낸다. 특정 변수만 뽑을 땐 model.params["나이"]처럼 부른다.
    2. model.pvalues (계수의 유의확률): 해당 변수의 계수가 0이 아닌지(통계적으로 유의미한지) 검정한 p-value다. 0.05 미만이면 유의한 변수다. 🚨 주의: 문제에서 "유의한 독립변수의 개수"를 물으면 상수항(Intercept)은 빼고 세야 하고(model.pvalues.drop("Intercept") < 0.05), "상수항 포함 유의한 항의 개수"를 물으면 그대로 (model.pvalues < 0.05).sum()을 센다!
    3. model.rsquared ($R^2$, 결정계수): 모형이 종속변수 변동의 몇 %를 설명하는지 나타내는 0~1 사이 값이다. (수정 결정계수를 물으면 model.rsquared_adj를 찍는다).

6. 로지스틱 회귀(Logit): 오즈비(np.exp)와 disp=0의 마법

👑 나카스 카스미 (1학년 후배): "아야세 에리 선배님! 이즈미 선배님! 로지스틱 회귀를 돌릴 때 .fit(disp=0)에서 disp=0 이 새끼는 도대체 역할이 뭐예요?! 그리고 왜 로지스틱 회귀계수(model.params)를 그대로 쓰지 않고 굳이 np.exp(model.params)를 씌워서 '오즈비(Odds Ratio)'로 바꾸는 건가요?!"

👩‍🏫 아야세 에리 & 🗡️ 카츠라기 이즈미 (강사진): "카스미! 속 시원하게 둘 다 알려줄게!
첫째, disp=0 (display=0)은 로지스틱 회귀가 정답을 찾아가는 지저분한 안내 문구(Optimization terminated successfully...)를 화면에 출력하지 말라고 입을 막는 음소거 스위치야! 계산 결과 숫자에는 아무 영향도 안 주지만, 채점 화면이 깔끔해지지!
둘째, 로지스틱 회귀의 원래 계수(.params)는 '로그 오즈($\ln(\frac{p}{1-p})$)'의 변화량이라서 음수·양수로 나와 사람이 직관적으로 몇 배인지 읽을 수가 없어! 그래서 로그($\ln$)를 벗겨내는 역함수인 자연상수 지수 np.exp(계수)를 씌워줘야 비로소 '독립변수가 1단위 증가할 때 사건이 일어날 오즈(승산)가 몇 배가 되는가!'를 뜻하는 오즈비(Odds Ratio)가 탄생하는 거야!"

  • 오즈(Odds)와 오즈비(Odds Ratio) 완벽 정리:
    • 오즈(승산): $\text{Odds} = \frac{p}{1 - p}$ (일어날 확률을 안 일어날 확률로 나눈 비율. 예: 이탈 확률이 $0.8$이면 안 할 확률은 $0.2$이므로 오즈는 $\frac{0.8}{0.2} = 4$배다).
    • 오즈비 공식: $$\text{Odds Ratio} = e^{\beta} = \text{np.exp}(\text{model.params})$$
    • 부호와 크기의 관계: 원래 회귀계수($\beta$)가 0이면 오즈비는 $e^0 = \mathbf{1.0}$이다! 따라서 원래 계수가 양수($\beta > 0$)면 오즈비는 1보다 크고(위험도/승산 증가), 원래 계수가 음수($\beta < 0$)면 오즈비는 1보다 작다(위험도/승산 감소)!

• 방식 1 (formula.api의 소문자 ols / logit): 문자열 수식 "종속 ~ 독립1 + 독립2"를 쓰면 상수항(Intercept)을 자동으로 넣어줍니다! 변수가 몇 개 안 될 때 가장 타자가 짧고 실수가 적습니다.
• 방식 2 (statsmodels.api의 대문자 sm.OLS / sm.Logit): 수식 문자열 없이 데이터프레임 열 묶음 X를 바로 넘길 수 있어서 변수가 10개, 20개일 때 편합니다. 단, 이 방식은 상수항을 자동으로 안 넣어주므로 반드시 X = sm.add_constant(df[['열1', '열2']])를 먼저 거쳐야 합니다! (상수항 이름은 const로 생성됩니다).

import statsmodels.api as sm
from statsmodels.formula.api import ols, logit

# [방식 1] 수식(Formula) 방식 -> 상수항(Intercept) 자동 포함!
# ═══════════════════════════════════════════════════════════
m_ols1 = ols("total ~ temp_c + humidity + windspeed", data=df).fit()

# ═══════════════════════════════════════════════════════════

# ═══════════════════════════════════════════════════════════
X_ols = sm.add_constant(df[["temp_c", "humidity", "windspeed"]])
m_ols2 = sm.OLS(df["total"], X_ols).fit()

X_log = sm.add_constant(df[["alcohol", "volatile_acidity", "sulphates"]])

import pandas as pd
from scipy import stats

df = pd.read_csv('alcohol-sample.csv')
red = df[df['wine_type'] == 'red']['alcohol']
white = df[df['wine_type'] == 'white']['alcohol']

# 등분산 미가정 Welch t-검정
result = stats.ttest_ind(red, white, equal_var=False)

print(round(float(red.mean() - white.mean()), 4))  # (1) -0.7154
print(round(float(result.statistic), 4))           # (2) -3.0371
print(round(float(result.pvalue), 4))              # (3) 0.0031
print("기각" if result.pvalue < 0.05 else "기각하지 못함")

  • 95% 신뢰구간 공식: 모표준편차를 모를 때 모평균의 신뢰구간은 $t$-분포(자유도 $n-1 = 11$)를 따르며, 이때 scale 파라미터에는 표준편차가 아니라 반드시 표본표준오차($\text{SE} = \frac{s}{\sqrt{n}}$)를 넣어야 합니다! (או 최신 Scipy에서는 result.confidence_interval(0.95).low 한 줄로도 똑같은 값 55675.695를 바로 뽑을 수 있습니다!).
import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv('bike-monthly.csv')

# 1. pivot으로 같은 달(month)끼리 나란히 맞추기
wide = df.pivot(index='month', columns='year', values='total')
diff = wide[2012] - wide[2011]
print(round(float(diff.mean()), 3))          # (1) 67206.083

# 2. 대응표본 t-검정
result = stats.ttest_rel(wide[2012], wide[2011])
print(round(float(result.statistic), 4))     # (2) 12.8287

# 3. 차이 평균의 95% 신뢰구간 하한
n = len(diff)
se = diff.std(ddof=1) / np.sqrt(n)
low, high = stats.t.interval(0.95, n - 1, loc=diff.mean(), scale=se)
print(round(float(low), 3))                  # (3) 55675.695

import pandas as pd
from scipy import stats

df = pd.read_csv('niji_training.csv')
diff = df['특훈후'] - df['특훈전']

# (1) 변화량의 평균과 표본표준편차
print(round(float(diff.mean()), 4), round(float(diff.std(ddof=1)), 4))

# (2) & (3) 대응표본 단측검정 (특훈후 > 특훈전)
res = stats.ttest_rel(df['특훈후'], df['특훈전'], alternative='greater')
print(round(float(res.statistic), 4))
print(round(float(res.pvalue), 6))
print("기각" if res.pvalue < 0.05 else "기각하지 못함")

  • 이번 시험에 꼭 나올 수 있는 OLS 고급 속성 3종 총정리:
    ① C(범주형변수): 수식 안에서 범주형 열(글자로 된 열이나 1,2,3 숫자로 코딩된 계절 열 등)을 자동으로 더미 변수(원-핫 인코딩, 기준 범주 1개는 자동 제외)로 처리해 주는 마법의 문법입니다!
    ② model.rsquared_adj & model.fvalue: 일반 결정계수는 model.rsquared이지만, 발문이 "수정된 결정계수(Adjusted R-squared)"를 물으면 model.rsquared_adj를 찍어야 합니다! 또한 회귀모형 자체의 F-통계량은 model.fvalue, 그 p-value는 model.f_pvalue에 들어 있습니다.
    ③ 회귀계수의 95% 신뢰구간 (model.conf_int()): ci = model.conf_int()를 부르면 각 변수의 0번 열에 하한(Lower), 1번 열에 상한(Upper)이 담긴 표가 나옵니다!
import pandas as pd
from statsmodels.formula.api import ols

df = pd.read_csv('hasu_goods.csv')
model = ols("굿즈지출액 ~ 시청시간 + 투표횟수 + C(소속유닛)", data=df).fit()

# (1) 수정 결정계수(rsquared_adj)와 모형 F-통계량(fvalue)
print(round(float(model.rsquared_adj), 4), round(float(model.fvalue), 4))

# (2) 시청시간 회귀계수와 95% 신뢰구간 상한(1번 열)
ci = model.conf_int()
print(round(float(model.params['시청시간']), 4), round(float(ci.loc['시청시간', 1]), 4))

# (3) 새로운 데이터 예측
new_fan = pd.DataFrame({'시청시간': [20], '투표횟수': [10], '소속유닛': ['미라쿠라파크']})
pred_val = model.predict(new_fan).iloc[0]
print(round(float(pred_val), 2))
