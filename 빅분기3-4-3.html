07 앙상블 분석

1) 앙상블 분석의 정의

앙상블(Ensemble) 기법은 주어진 자료로부터 여러 개의 개별 학습 모형을 만든 후 학습모형들을 조합하여 하나의 최종 모형을 만드는 개념이다. (백지장도 맞들면 낫다!)

  • ① 약학습기(약분류기, Weak Learner): 무작위 선정이 아닌 성공확률이 높은, 즉 오차율이 일정 이하(50% 이하)인 학습 규칙을 말한다. 가능성 있는 다양한 복수의 기초 학습 규칙이다.

스팸 메일 처리 방법을 개발한다고 가정 시 스팸을 판정하는 여러 가지 기준이 존재할 것이다. 스팸 여부를 'Yes/No'로만 판정한다고 가정하면

기준판정
제목에 광고가 붙은 경우스팸(Yes)
본문에 보험/대출이 들어간 경우스팸(Yes)
보낸이가 내 주소록에 있는 경우스팸아님(No)
$\cdots$$\cdots$

상기의 경우처럼 스팸 여부를 판단하는 여러 기준들은 모든 메일에 적용할 만큼 강력한·확실한 기준도 있지만 그러하지 못한 기준도 있다. 이와 같이 결과 도출에 실패 가능성을 어느 정도 내포한 여러 낱개의 학습 기준을 약학습기(Weak Learner)라고 한다.

  • ② 강학습기(강분류기, Strong Learner): 여러 개의 약학습기(Weak Learner)들로부터 앙상블 투표 및 결합을 통해 만들어내는 강력한 최종 학습 규칙을 의미한다.

자연어 처리의 핵심 뼈대인 'Text to Vector' 기술과 데이터 마이닝의 응용, 그리고 새로운 대단원인 '앙상블'의 서막이야! 시험 문제에서 꼬아 내는 포인트들을 일망타진해 주마(...).

  • Text to Vector (텍스트 수치화) 3대장:
    • Bag-of-Words(BoW): 순서나 문맥 따위 쌩까고 오직 '단어 빈도(카운트)'만 세는 무식한 방법이야.
    • TF-IDF: 무조건 시험에 나와! 핵심은 '내 문서에선 자주 나오는데(TF), 딴 문서에선 흔해 빠진 단어(IDF)는 가치를 깎아버린다'는 거야.
    • 임베딩(Embedding - Word2Vec 등): 단어를 냅다 고정 크기의 실수 벡터 공간에 맵핑해서 '단어 간의 의미적 유사성'을 보존해!
  • 마이닝 삼총사 말장난 저격: 오피니언 마이닝은 텍스트에서 빡침/기쁨 같은 주관적 감정을 캐내는 '감정 분석'이고, 리얼리티 마이닝은 '스마트폰 센서, GPS' 등을 활용해 실제 인간 행동을 추적하는 거야!
  • 앙상블(Ensemble)의 첫걸음: 백지장도 맞들면 낫다는 걸 머신러닝으로 구현했지. 약학습기(오차율 50% 이하)들을 수백 개 모아서 투표(다수결)시키는 순간, 인간계 최강의 강력한 모델(Strong Learner)로 환골탈태하게 돼! 본문에 나오는 "모델의 분산(Variance)을 줄여준다"는 문장이 앙상블의 가장 핵심 목표란다!

2) 앙상블 분석의 이해

동일한 학습 알고리즘을 이용할 때, 앙상블 분석이 한 개의 단일학습기(Single Learner)에 의한 분석보다는 더 나은 예측 분석 성능을 이끌어낼 수 있다.

※ 앙상블 기법은 다양한 약학습기를 통해 강학습기를 만들어가는 훌륭한 과정이다.

① 장점

  • 정확성 향상: 앙상블 모델은 여러 개의 기본 모델의 예측 결과를 종합하여 더 정확한 예측을 제공한다.
  • 과적합 방지: 단일 모델에서 발생한 과적합 문제를 회피할 수 있다. 앙상블의 각 모델은 서로 다른 부분에 초점을 맞추기 때문에 일반화 성능을 높인다.
  • 분산 감소: 여러 모델의 예측 값을 평균하거나 다수의 결과를 취하여 전체적인 예측 오차(분산)를 줄일 수 있다.
  • 다양한 모델 적용 가능: 서로 다른 알고리즘으로 구성된 기본 모델을 결합하여 다양한 정보를 융합 활용할 수 있다.

② 단점

  • 계산 복잡성 증가: 여러 개의 기본 모델을 동시에 트레이닝 해야 하므로, 계산 시간과 컴퓨터 자원이 기하급수적으로 더 많이 필요하다.
  • 해석 어려움 (블랙박스화): 단일 의사결정나무 모델에 비해 설명력이 확 낮아질 수 있다. 여러 모델의 결정 과정이 짬뽕되어 복잡해지기 때문이다.
  • 구현 복잡성: 앙상블 모델의 구현과 튜닝(Hyperparameter)이 상대적으로 매우 복잡하여 높은 전문 지식이 필요하다.

3) 앙상블 분석의 종류 (★ 출제율 500%)

① 보팅(Voting)

보팅은 뜻 그대로 '투표'를 통해 결정하는 방식이다. 보팅은 배깅(Bagging)과 다수결 투표방식이라는 점에서는 유사하지만 데이터 활용법에서 큰 차이점이 있다.

  • 보팅은 데이터셋은 그대로 두고 서로 다른 여러 학습 모델(알고리즘)을 조합해서 사용한다. (예: 의사결정나무 + SVM + KNN을 모아 투표시킴). 반면 배깅은 '같은 알고리즘' 내에서 다른 표본(샘플) 조합을 쪼개서 사용한다.
  • 하드 보팅(Hard Voting): 모델들이 뱉어낸 최종 결과값(A or B)을 그대로 다수결 투표해서 결정하는 방식이다.
  • 소프트 보팅(Soft Voting): 최종 결과물이 나올 확률 값(%)을 다 더해서 평균을 구한 뒤, 가장 높은 확률을 가진 클래스를 최종 값으로 도출해내는 더 정교한 방법이다.

② 부스팅(Boosting)

가중치(Weight)를 활용하여 연속적인(Sequential) 약학습기를 생성하고, 앞 모델의 '오답'에 집중하게 만들어 강학습기로 진화시키는 하드코어 방법이다.

  • 다른 앙상블 기법과 가장 큰 차이점은 바로 순차적인 학습을 하며 오답에 가중치(weight)를 부여해서 약점을 보완해 나간다는 점이다.
  • 순차적이기 때문에 병렬 처리(Parallel)에 어려움이 있고, 그렇기 때문에 다른 앙상블(배깅 등) 대비 학습 시간이 엄청나게 오래 걸린다는 단점이 있다.

③ 배깅(Bagging: Bootstrap Aggregation)

원본 데이터에서 샘플을 무작위 복원 추출로 여러 번 뽑아(Bootstrap) 각 모델을 병렬로 독립 학습시킨 후, 그 결과물을 평등하게 집계(Aggregation)하는 평화로운 방법이다.

▲ 배깅(Bagging) 설명도
  • 우선, 데이터로부터 부트스트랩을 한다(복원 랜덤 샘플링). 부트스트랩한 데이터로 여러 트리 모델의 학습을 거친다.
  • 집계(Aggregation) 방식: 범주형 자료(Categorical Data)는 투표 방식(Voting, 다수결)으로 결과를 집계하며, 연속형 자료(Continuous Data)는 평균(Average)으로 집계한다.
  • 배깅은 모델의 분산을 줄여 과적합을 막는 간단하면서도 강력한 방법이며, 의사결정나무에 배깅을 융합한 갓-모형이 바로 랜덤 포레스트(Random Forest)이다.

드디어 시험지에 무조건 2~3문제 출제되어 수험생 합격을 캐리하는 앙상블(Ensemble) 3대장 형님들이 정식으로 위용을 드러내셨어! 시험 문제에서 말장난 치는 그물을 갈기갈기 찢어줄게!

  • 보팅(Voting) vs 배깅(Bagging): 날개에서도 대놓고 비교하라고 유혹하고 있지? 이거 구별 못 하면 바로 과락이야!
    • 보팅: 문제집(데이터셋)은 1개인데, 푸는 학생(알고리즘)들이 의사결정나무, 로지스틱, KNN 등 짬뽕으로 섞여서 투표하는 거야.
    • 배깅: 푸는 학생들은 전부 똑같은 녀석들(주로 의사결정나무)만 쓰는데, 대신 원본 문제집에서 복원 추출로 모의고사를 여러 개 찢어 만들어서 각각 독립적으로 병렬 학습시키는 방식이야. (대표적 예: 랜덤포레스트)
  • 하드 보팅 vs 소프트 보팅:
    • 하드 보팅: 무지성 다수결! 모델 3개가 "러브라이브, 러브라이브, 뱅드림" 이라고 예측하면 2표 얻은 '러브라이브'가 승리해.
    • 소프트 보팅: 각 모델이 출력한 '확률값의 평균'을 내! 모델 A가 러브라이브 확률 90%, B가 45%, C가 40%면 평균 58.3%로 '러브라이브'가 이기는 훨씬 합리적인 방식이지.
  • 부스팅(Boosting)의 찌리릿한 매력: 배깅은 애들이 한 번에 좌르륵 각자 문제집을 푸는 '병렬(Parallel)' 방식이라 속도가 빨라. 반면 부스팅은 무조건 앞 모델이 먼저 끝나야 뒤 모델이 시작하는 지독한 '순차적(Sequential)' 방식이야. 1번 애가 문제를 풀다가 틀린 오답 노트에 '가중치(Weight)'를 떡칠해서 2번 애한테 넘겨주기 때문이지. "성능은 지존급인데, 속도가 너무 느리고 가중치 뇌절하다가 과적합에 털리기 쉽다"는 치명적 단점이 시험에 오답 선지로 자주 나오니까 꼬아서 내면 뚝배기 깨버리자!

④ 스태킹(Stacking)

스태킹은 앙상블 학습의 진화된 한 종류로, 여러 개의 개별 기초 모델(Base Model)을 조합하여 예측 성능을 향상시키고, 그 예측 결과물들을 싹 다 긁어모아 새로운 '메타 모델(Meta Model)'의 입력 데이터로 짬뽕시켜 최종 결론을 도출하는 궁극의 방법이다.

[참고/날개] 메타 모델 (Meta Model)
스태킹 앙상블 학습에서 사용되는 개별 1차 모델들의 예측 결과를 '새로운 입력 데이터(Features)'로 받아 최종적인 2차 예측을 수행하는 블렌더(Blender) 대장 모형.
  • 스태킹은 다양한 모델들의 예측 결과를 결합하기 때문에 개별 모델들 간의 다양성이 중요하다. 서로 다른 알고리즘, 다른 하이퍼파라미터를 가진 모델들을 조합함으로써 다양성을 확보한다. 과적합을 방지하기 위해 교차 검증(CV)을 사용하여 개별 모델을 학습하는 것이 일반적이다.

▶ 스태킹의 6가지 주요 단계 (순서 암기)

  1. 데이터 분할: 원본 데이터를 훈련 데이터와 테스트 데이터로 분할한다.
  2. 개별 모델 학습: 분할된 훈련 데이터를 사용하여 서로 다른 알고리즘(RF, SVM, KNN 등)을 가진 다양한 1차 개별 모델들을 병렬로 학습시킨다.
  3. 개별 모델 예측: 학습된 개별 모델들을 사용하여 테스트 데이터에 대한 1차 예측 결과값들을 쫙 뽑아낸다.
  4. 메타데이터 준비: 개별 모델들이 만든 1차 예측 결과(확률값 등)를 취합하여 새로운 특성(Feature) 데이터셋인 '메타데이터'로 준비한다.
  5. 메타모델 학습: 갓 만들어진 메타데이터와 실제 타깃(label) 정답값을 사용하여 2차 메타모델(또는 블렌더)을 학습시킨다.
  6. 최종 예측: 테스트 데이터에 대한 개별 모델의 예측 결과를 메타모델에 입력으로 사용하여 완벽한 최종 예측을 수행한다.

⑤ 앙상블 모형의 최적화

앙상블 모형의 최적화는 단순히 모델을 합치는 것을 넘어 다양한 측면에서 튜닝되어야 한다.

  • 다양한 알고리즘과 모델 사용: 개별 모델들을 다양한 알고리즘으로 구성하여 다양성을 증가시키고 예측 성능을 향상시킨다.
  • 개별 모델의 다양성 확보: 서로 다른 특징, 하이퍼파라미터 조합, 데이터 샘플링(부트스트래핑 등)으로 다양성을 강제로 확보한다.
  • 하이퍼파라미터 최적화: 그리드 탐색, 랜덤 서치, 베이지안 최적화 등을 사용하여 하이퍼파라미터 공간을 탐색하고 성능을 개선한다.
  • 교차 검증을 통한 성능 평가: 교차 검증(K-Fold 등)을 통해 각 개별 모델의 예측 성능의 거품을 빼고, 최적의 모델을 안정적으로 선택한다.
  • 앙상블 크기 결정: 앙상블 모델의 크기는 개별 모델의 수로 결정되며, 일반적으로 트리가 많을수록 예측 성능이 향상되지만 일정 크기 이상으로 증가하면 계산 시간만 잡아먹고 추가적인 성능 향상은 둔화(제한)된다. 적절한 가성비 컷을 찾아야 한다.
  • 앙상블 멤버 간의 상관 관계 관리: 너무 유사하게 베껴 쓴 모델들을 결합하면 앙상블의 의미가 퇴색되어 성능 개선을 기대하기 어렵다.

08 비모수 통계 (Non-Parametric Statistics)

1) 모수(매개변수, 파라미터, Parameter)의 정의

모수는 수학과 통계학에서 모집단이라는 거대한 시스템이나 함수의 특정한 성질(평균, 분산 등)을 나타내는 고정된 상숫값을 말한다. 일반적으로는 $\theta$(세타)라고 표현되며, 독립변수는 변하지만 매개변수는 일정하다.

2) 비모수 통계의 개념

비모수 통계(Non-Parametric Statistics)는 통계학에서 모수(평균/분산 등)에 대한 깐깐한 가정을 전제로 하지 않고, 모집단의 형태(분포)에 관계없이 주어진 데이터에서 '직접 순위나 부호'를 계산하여 통계학적 검정을 하는 유연한 분석이다.

  • 상대적으로 모수 통계(Parametric Statistics)는 데이터가 예쁜 종 모양의 '정규분포'를 따른다는 강력한 가정을 하고 통계적 추론(t-test, ANOVA)을 하는 것이다.

3) 비모수 통계법의 사용조건 (★ 오답 선지 100% 출제)

어떨 때 깐깐한 모수 통계를 버리고 자유로운 비모수 통계로 도망칠 수 있는가?

  • ① 자료가 나타내는 모집단의 형상이 정규분포가 아닐 때 (가장 중요!)
  • ② 자료가 나타내는 현상이 로그/루트 변환을 때려도 정규분포로 적절히 변환되지 못할 때
  • ③ 자료의 표본(Sample Size)이 30개 미만으로 너무 적을 때 (소표본)
  • ④ 자료들이 서로 독립적일 때
  • ⑤ 변인의 데이터 척도가 연속형(등간/비율)이 아니라 명목척도나 서열척도(순위)일 때

4) 비모수 통계의 특징

  • 가정(정규성)을 만족시키지 못한 상태에서 억지로 모수 통계를 돌림으로써 발생할 수 있는 끔찍한 추론 오류를 줄일 수 있다.
  • 키나 몸무게 같은 연속형 자료가 아니라, '매우 만족/불만족' 같은 질적 척도(순위)로 측정된 자료도 훌륭하게 분석이 가능하다.
  • 분산이나 평균 같은 복잡한 계산 대신 '순위(Rank)'나 '부호(+/-)'만 따지기 때문에, 비교적 신속하고 쉽게 통계량을 구할 수 있으며 결과 해석이 매우 직관적이다.
  • 많은 표본을 추출하기 어려운 소표본(n<30) 경우에 사용하기 안성맞춤이다.

* 비모수검정은 값 그 자체가 아니라 순위(rank)를 사용하거나 데이터를 재배열하는 등의 방법으로 수행한다.

5) 비모수적 통계 검정법

비모수검정(Non-parametric Test)은 데이터가 정규분포를 따른다는 가정 없이, 데이터의 '순위'나 '부호'만을 사용하여 수행되는 유연한 검정 방법이다.

▶ 비모수검정의 장단점

구분 주요 내용
장점 • 유연성: 데이터가 특정 정규 분포를 따르지 않아도 자유롭게 사용할 수 있음.
• 적용 범위 넓음: 서열 척도 등 다양한 질적 데이터 유형에 적용 가능.
• 순위 사용: 실제 값 대신 순위(1등, 2등)를 사용하여, 미쳐 날뛰는 극단값(Outlier)의 어그로 영향을 완벽하게 줄일 수 있음.
단점 • 효율성 저하: 만약 데이터가 진짜로 예쁜 정규분포를 띠는 '동일한 조건'이라면, 당연히 모든 정보를 다 쓰는 모수적 검정보다 검정력(파워)이 살짝 낮음.
• 큰 표본 필요: 매우 작은 표본에서는 검정력이 충분히 발휘되지 않을 수 있음. (이건 상황에 따라 양날의 검)

① 부호검정 (Sign Test)

  • 관측치들 간에 '같다' 혹은 '크거나 작다(+/-)'라는 주장이 사실인지 아닌지를 가장 1차원적으로 검정한다.
  • 데이터의 순서나 크기에 대한 가정을 일절 하지 않으며, 오직 관측값들의 증감 부호(+/-)만을 카운트하여 검정을 수행한다.
  • 순위나 크기 정보까지 다 버리기 때문에 정보 손실이 너무 커서, 보다 정확한 분석을 위해서는 윌콕슨 같은 다른 비모수 검정을 고려해야 한다.

② 윌콕슨 부호순위 (Wilcoxon Signed-Rank) 검정 ★ (모수: 대응표본 t-검정 대안)

  • 부호검정의 단점을 보완하여, 크거나 작음을 나타내는 부호(+/-) 뿐만 아니라 관측치 간 차이의 '크기 순위(Rank)'까지를 모두 고려하여 정밀하게 검정한다.
  • 대응 표본(Paired Sample)에 사용된다. 즉, 동일한 개체에 대해 약 투여 전/후 두 번 측정한 데이터의 짝이 맺어진 경우 차이에 대한 가설을 검정한다.
  • 예시: 다이어트 보조제 복용 전과 후의 체온(몸무게) 변화 비교, 효빈도시철도 개통 전후 상권 매출액 변화 등을 비교할 때 사용한다.

③ 만-위트니 U (Mann-Whitney U) 검정 ★ (모수: 독립표본 t-검정 대안)

  • 두 '독립된' 집단(Independent Sample) 간의 중심위치를 비교하기 위하여 사용하는 대표적인 비모수 검정 방법이다.
  • 두 그룹 간의 위치적인 차이(누가 전반적으로 랭크가 더 높은가)에 대한 가설을 검정한다.
  • 예시: 남학생과 여학생(두 집단)의 빅분기 성적 비교, 효빈광역시 1호선과 2호선 승객 만족도 비교 등에서 사용한다.

④ 크루스칼-왈리스 (Kruskal-Wallis) 검정 ★ (모수: 일원배치 분산분석 ANOVA 대안)

  • 만-위트니의 확장판. 3개 이상의 '독립된' 그룹(집단)의 관측값 중앙값 차이를 한꺼번에 비교하는 경우에 사용된다.
  • 그룹 간의 순위 차이에 대한 가설을 검정한다.
  • 예시: 세 개 이상의 다이어트 약 효과를 동시에 비교하거나, 효빈도시철도 1, 2, 3호선의 소음도 차이를 비교할 때 사용한다.

(Wilcoxon Signed-Rank Test)		 • 두 관련 샘플 (짝지어진/대응 표본) 간의 차이 비교
• 주로 동일 대상에 대해 사전-사후(전/후) 두 번 측정한 데이터를 비교할 때 쓴다.
만-위트니 U 검정
(Mann-Whitney U Test)		 • 두 독립 샘플 (완전 남남인 집단)의 중앙값 차이 비교
• 남vs여 처럼 서로 엮이지 않은 두 그룹 간 차이를 볼 때 쓴다.
크루스칼-왈리스 검정
(Kruskal-Wallis Test)		 • 세 개 이상의 독립 샘플 간의 차이 비교
• 일원배치분석(ANOVA)의 비모수 대안으로 쓴다.
프리드만 검정
(Friedman Test)		 • 세 개 이상의 관련 샘플 (반복 측정 표본) 간의 차이 비교
• 반복측정 분산분석(Repeated Measures ANOVA)의 대안.
카이제곱 검정
(Chi-Square Test)		 • 명목(범주형) 데이터의 기대빈도와 관측빈도 차이 비교 (독립성/동질성 검정)

드디어 필기시험에서 과락자들을 대량 생산하는 최종 보스, '비모수 통계 검정 맵핑'이야! 모수 통계(t-test, ANOVA)는 잘 외워놓고 비모수만 오면 대가리가 리셋되는 오빠들을 위해 효빈위키 1타 강사 드립 칠 테니 통째로 외워버려!

  • 독립된 2집단 평균 비교: 모수가 `독립표본 t-검정`이면 $\rightarrow$ 비모수는 만-위트니 U (Mann-Whitney U)야. (외우기: 독립적인 남(Man)자가 위트가 있다!)
  • 짝지어진(전/후) 2집단 비교: 모수가 `대응표본 t-검정`이면 $\rightarrow$ 비모수는 윌콕슨 부호순위 (Wilcoxon Signed-Rank)야. (외우기: 전/후 사정 대응을 하려면 윌콕슨 오빠한테 사인(Sign)부터 받아라!)
  • 독립된 3집단 이상 비교: 모수가 `일원배치 분산분석(ANOVA)`이면 $\rightarrow$ 비모수는 크루스칼-왈리스 (Kruskal-Wallis)야. (외우기: 분산분석 ANOVA 형님들이 3명 이상 모여서 힙합 크루(Kruskal)를 결성했다!)
  • 관련된 3집단 이상 반복 비교: 모수가 `반복측정 ANOVA`이면 $\rightarrow$ 비모수는 프리드만 (Friedman)이야. (외우기: 반복해서 야근하면 금요일에 프리(Friedman)해진다!)

② 세 개 이상의 관련된 표본 간의 차이를 평가할 때
③ 동일한 집단의 사전-사후 테스트 결과를 비교하려 할 때
④ 범주형 데이터에서 두 변수 간의 연관성을 검정할 때

[해설 및 출제자 의도 저격]
개념 체크 문제 비주얼을 보세요. 대놓고 '동일 집단의 사전-사후 테스트(대응표본, Paired)'라고 힌트를 퍼다 줬습니다. 그러니까 당연히 정답은 전/후 변화를 랭킹 매기는 '윌콕슨 부호순위 검정'입니다.
• 두 독립된 집단(남/녀)의 중앙값을 비교할 때는 만-위트니 U 검정이 적절합니다.
• 세 개 이상의 관련된 표본(1달차, 2달차, 3달차) 간의 차이를 평가할 때는 프리드만 검정이 적절합니다.
• 범주형 데이터(A형, B형)에서 두 변수 간의 연관성을 검정하는 것은 카이제곱 검정이 적절합니다.
