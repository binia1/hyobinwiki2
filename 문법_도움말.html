1. 개요 [편집]

효빈위키의 문법 도움말입니다. 효빈위키가 사용하는 위키 엔진이 제공하는 문법이라 하여 '효빈마크'라고도 합니다. 이 문서에서는 기본적인 수준의 위키 문법들을 정리했으며, 효빈위키:문법 도움말/심화 문서에서 고급 문법을 확인하실 수 있습니다. 효빈위키:문법 도움말/개발 문서에서는 위키 문법을 처리하는 원리 등을 설명합니다.

2. 텍스트 [편집]

🔗 관련 심화 문법:
{{{#!wiki style= ...}}} 문법을 사용한 응용 텍스트 문법 (텍스트 정렬, 자간 조절, 줄바꿈 기준 설정, 그라데이션 효과)
HTML 코드 구현을 통한 응용 텍스트 문법 (텍스트 배경 색상, 텍스트 그림자·네온·외곽선 효과)
서식이 적용된 텍스트의 개행은 줄바꿈(엔터 키)이 아닌 [br] 매크로를 사용해야 합니다.

텍스트의 크기를 -5와 +5 사이의 정수를 입력하여 조절할 수 있습니다. 스킨의 기본 텍스트 크기를 기준으로 상대 단위인 em을 사용하는 방식으로 작동합니다. em 등 단위를 사용해 글자 크기를 조절하는 방법은 효빈위키:문법 도움말/심화 참고.[2]

2.3. 텍스트 색상 [편집]

텍스트의 색상을 헥스 코드[3]나 CSS 색상명[4]을 입력하여 조절할 수 있습니다. 다크 모드 대응 색상을 지정하지 않으면 자동으로 다크모드 대응 색상으로 변경되며, 라이트 모드와 동일한 색상을 의도하시는 경우 명암비에 맞춰서 다크 모드 대응 색상을 별도로 지정합니다.
유형입력출력비고
기본 예시 {{{#ff0000 텍스트}}}텍스트 헥스 코드와 CSS 색상명 모두 대소문자 구별없이 입력 가능합니다. 예시와 같이 일부 색상의 경우 세 자리만 입력하는 축약형 헥스코드[5]를 사용할 수도 있습니다.
투명도 요소가 추가된 #RRGGBBAA 색상은 지원하지 않습니다.
{{{#f00 텍스트}}}
{{{#red 텍스트}}}		텍스트
{{{#880088 text}}}text
{{{#808 text}}}
{{{#purple text}}}		text
{{{#00a495 효빈위키색}}}[6]효빈위키색
{{{#transparent 투명색}}}투명색
다크 테마용 색상 별도 지정 {{{#888,#ff0 다크텍스트}}}다크텍스트 첫 번째 색상은 라이트 테마, 두 번째 색상은 다크 테마에서 적용됩니다. 두 색상코드 끼리는 쉼표를 사이에 두고 붙여써야만 합니다.
색상 문법이 적용되지 않은 일반 텍스트는 라이트 모드에서 #212529(검은색), 다크 모드에서 #e0e0e0(옅은 회색) 색상이 자동으로 적용됩니다.
{{{#gray,#yellow 다크텍스트}}}다크텍스트
밑줄 서식과 중첩 {{{#red __밑줄 포함__}}}밑줄 포함 색상 문법과 밑줄 문법의 순서에 따라 밑줄에 색상 지정 여부가 다릅니다.
__{{{#red 밑줄 제외}}}__밑줄 제외
크기 서식과 중첩 {{{+1 {{{#blue 큰글자파랑}}}}}}큰글자파랑 밑줄과 달리 크기 서식을 색상과 결합할 경우 문법의 순서가 출력에 영향을 미치지 않습니다.
{{{#blue {{{+1 큰글자파랑}}}}}}큰글자파랑

3. 하이퍼링크 [편집]

문서 내에 다른 문서나 외부 사이트로 가는 하이퍼링크를 텍스트나 이미지 파일로 출력할 수 있습니다.
유형입력출력비고
기본[[문서]]문서 문서명에 대괄호나 백슬래시, 수직선(|)이 들어갈 경우 앞에 백슬래시(\)를 입력해야 정상 생성됩니다.
링크 문서와 출력을 다르게[[문서|출력글자]]출력글자 출력글자 부분에 뭔가를 입력하고 문서 부분에 아무것도 입력하지 않으면 기존 문서로 링크되고, 출력글자는 볼드 처리가 됩니다.
링크 텍스트에 색상 적용[[문서|{{{#ff85b1 문서}}}]]문서 색상뿐 아니라 글자 크기도 적용할 수 있습니다.

4. 리다이렉트 [편집]

리다이렉트 문서는 특정 검색어 검색 시 목적지 문서로 즉시 넘겨주는 문서입니다. 리다이렉트 문서의 생성법은 일반 문서 생성 방법과 동일하며, 아래 입력 내용만을 적어야 합니다. 이외의 추가로 적은 내용들은 모두 자동 삭제됩니다.
유형입력비고
기본#redirect 목적지 문서
#넘겨주기 목적지 문서[9]		해시(#)가 들어갈 경우 해시 앞에 \를 입력해야 정상 작동됩니다.
특정 문단으로 리다이렉트#redirect 목적지 문서#s-문단 번호
#redirect 목적지 문서#문단명		목적지 문서에 해당 앵커나 문단이 없을 경우 문서 최상단으로 리다이렉트됩니다.

5. 이미지 파일 [편집]

파일 업로더를 통해 생성한 파일 문서의 이미지 파일을 문서 내에 출력할 수 있습니다. 또한 매개변수를 이용해 이미지의 속성을 지정할 수 있습니다. 문서 내에 출력된 이미지 파일은 해당 이미지 파일의 파일 문서로의 하이퍼링크 기능도 겸합니다. 외부 이미지를 업로드하지 않고 효빈위키 문서 내에 출력하는 방법은 없습니다.
유형입력비고
기본[[파일:example.png]][10]텍스트 하이퍼링크로 하고자 하는 경우, 맨 앞에 쌍점(:)을 붙여 [[:파일:example.png]]와 같이 작성합니다.
매개변수 포함 단일[[파일:example.png|매개변수]]width=숫자와 같이 사용합니다.
매개변수 중첩[[파일:example.png|매개변수1&매개변수2&...]]width=숫자&align=위치와 같이 앰퍼샌드(&) 구분자를 넣습니다.
유형매개변수비고
픽셀 지정width=숫자
height=숫자		이미지의 크기를 높이 변경으로 지정하는 것은 권장되지 않습니다. width 변수와 height 변수를 동시에 사용하면 비율이 달라질 수 있는데 object-fit 매개변수를 사용하면 비율을 유지할 수 있습니다.
비율 지정width=숫자%
height=숫자%		사이트나 표의 고정폭 대비 이미지 파일의 비율을 지정합니다.
주의: 표에 넣지 않고 단독으로 이미지 너비 지정을 할 경우 가능한 한 절대 수치를 이용해주세요.
정렬 지정align=위치왼쪽 정렬: left / 가운데 정렬: center 또는 middle / 오른쪽 정렬: right
배경색 지정bgcolor=#RRGGBB투명한 값이 있는 파일의 배경색을 지정할 수 있습니다.
라이트/다크 모드 지정theme=상태라이트 모드: light, 다크 모드: dark
모서리 곡률 지정border-radius=픽셀모서리 곡률을 지정합니다.
픽셀화rendering=pixelated안티에일리어싱이 적용되지 않게 해 줍니다.
크기 맞춤object-fit=fill
object-fit=contain

8. 리스트 [편집]

8.1. 기본 형식 [편집]

리스트를 추가할 수 있습니다. 공백을 ○으로 표시합니다. 별표 앞에 띄어쓰기를 생략하면 정상 출력되지 않습니다.
○* 리스트 1 ○○* 리스트 1.1 ○* 리스트 2 ○○* 리스트 2.1 ○○○* 리스트 2.1.1

8.2. 번호 있는 리스트 [편집]

번호 있는 리스트를 표기할 때, 1., 2., 3. 방식이 아니라, 모두 1.로 표기합니다. 1., a., A., i., I. 형태를 지원합니다. 리스트의 시작하는 숫자를 바꾸고자 할 경우, 1.#시작숫자를 붙입니다.

8.3. 리스트와 줄바꿈 [편집]

줄바꿈을 통해 한 줄 이상을 비우면 앞의 리스트는 종료되고 뒤의 리스트를 새로 시작하는 것으로 간주합니다. 같은 리스트 내에서의 줄바꿈은 [br] 매크로나 엔터키로 할 수 있습니다. 리스트가 복잡한 경우 매크로를 사용할 것이 권장됩니다.

9. 각주 [편집]

각주를 생성할 수 있습니다. [* 텍스트] 로 사용합니다. 각주 이름을 따로 지정하려면 [*A 텍스트] 로 지정하며, 문서 내 여러 위치에 같은 각주를 [*A]로 삽입할 수 있습니다. 숫자로 지정하는 것은 권장되지 않습니다. 각주 안의 각주는 금지되어 있습니다.

10. 인용문 [편집]

인용문을 입력할 수 있습니다. 문법 사용 시 부등호(>)를 입력합니다.
> 인용문1 >> 인용문2

13. 테이블(표) [편집]

13.1. 기본 형태 [편집]

테이블의 한 줄은 || 로 시작해 || 로 끝납니다.
|| 테이블 || 테이블 || || 셀 || 셀 ||

13.2. 셀 합치기 [편집]

가로 합치기: 합치고자 하는 셀의 수만큼 <-수>를 입력합니다. (예: ||<-2> 두칸짜리 ||)
세로 합치기: 합치고자 하는 셀의 수만큼 <|수>를 입력합니다. (예: ||<|2> 두줄짜리 ||)
가로세로 합치기: <-3><|2> 형식으로 두 가지를 같이 입력합니다.

13.3. 테이블과 셀 텍스트의 정렬 [편집]

테이블 정렬: <tablealign=center> 등
셀 텍스트 가로정렬: <(> (왼쪽), <:> (가운데), <)> (오른쪽)
셀 텍스트 세로정렬: <^|1> (위), <|1> (가운데), <v|1> (아래)

13.4. 테이블의 크기와 색상 [편집]

테이블 전체 너비: <tablewidth=600px>
셀 너비/높이: <width=200px>, <height=100px>
테이블 배경색: <tablebgcolor=#RRGGBB>, <bgcolor=#RRGGBB> (개별 셀)
색상 지정시 <bgcolor=#00a495,#2d2f34>와 같이 콤마로 구분하여 다크 테마용 색깔을 지정할 수 있습니다.[23][24]

13.5. 기타 문법 [편집]

셀 기본 여백 제거: <nopad>
단어 단위 줄 바꿈: <keepall>
머리글 및 정렬: <thead>, <sortable>
