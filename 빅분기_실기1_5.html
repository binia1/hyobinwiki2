1.1. 마스킹(Masking)의 함정: 왜 두 코드의 .shape[0] 결과가 다를까?

💧 오사카 시즈쿠 (수강생): "에리 선배님, emp.csv(전체 30행)에서 이름에 '서'가 들어가는 직원이 몇 명인지 세려고 아래 두 코드를 쳐봤는데, 왜 1번은 30이 나오고 2번은 4가 나오는 건가요? 둘 다 str.contains('서')를 썼는데 너무 헷갈려요…!"

# [코드 A] 왜 이건 30이 나올까? print(df["이름"].str.contains("서").shape[0]) # [코드 B] 왜 이건 4가 나올까? print(df[df["이름"].str.contains("서")].shape[0])

👩‍🏫 아야세 에리 (KKE 센터장): "하라쇼! 시즈쿠, 아주 핵심적인 질문이야. 이 차이를 이해하려면 판다스의 '마스크(Mask, O/X 채점표)' 원리를 알아야 해!"

  • 코드 A의 정체 — df["이름"].str.contains("서")는 'O/X 채점표(마스크)' 자체다!
    컴퓨터가 30명의 이름을 0번부터 29번까지 위에서 아래로 훑으면서 "서"가 들어 있으면 True, 없으면 False라고 적힌 30칸짜리 O/X 용지(Series)를 만듭니다: [True(김서준), False(이지우), False(박도윤), ...].
    거기에 곧바로 .shape[0](길이 재기)을 붙였으니, True가 몇 개인지 센 게 아니라 "O/X 채점표 용지가 총 몇 줄짜리냐?"를 잰 것입니다! 30명을 검사한 용지니까 당연히 전체 행 수인 30이 나옵니다. (만약 이 채점표 상태에서 바로 개수를 세고 싶다면 .shape[0] 대신 .sum()을 붙여야 True(1)만 더해져서 4가 나옵니다!)
  • 코드 B의 정체 — df[ ...채점표... ]는 채점표로 걸러낸 '진짜 새 표(DataFrame)'다!
    바깥에 df[ ... ]로 한 번 더 감싸면, 판다스는 방금 만든 O/X 채점표를 원본 표 df 위에 겹쳐 놓고 True인 행(김서준, 권서연, 황준서, 유서윤, 서준혁 등)만 남긴 뒤 False인 행은 가위로 싹둑 잘라 버립니다!
    이렇게 살아남은 사람들로만 구성된 새로운 표의 행 개수(.shape[0])를 쟀으니, 우리가 진짜로 원하던 조건 충족 인원수가 나오는 것입니다!

1.3. 날짜형(.dt)의 딜레마: 왜 df["입사일"].dt.min().date()는 에러가 날까?

🌸 오토무네 코즈에 (기계치 수강생): "우후후… 이즈미, 히메… 큰일이야. 분명히 날짜 열을 다룰 때는 .dt를 꼭 붙이라고 배웠는데, df['입사일'].dt.min().date()라고 치니까 컴퓨터가 빨간 글씨로 화를 내면서 멈춰버렸어… 내가 또 노트북 회로를 망가뜨린 걸까…?"

🗡️ 카츠라기 이즈미 & 🎮 안요지 히메 (강사진): "코즈에 선배, 진정하세요! 노트북 고장 난 거 아니에요! 이건 판다스에서 '여러 개가 묶인 기차(Series 덩어리)'와 '기차에서 내린 승객 1명(Timestamp 낱개)'을 구분하지 않아서 생긴 아주 유명한 함정이에요!"

  • 언제 .dt를 붙이나요? ➡️ 대상이 '기차 전체(Series 덩어리)'일 때!
    df["입사일"]은 직원 30명의 입사일이 줄줄이 들어 있는 Series(덩어리)입니다. 기차 전체에 탄 승객 30명에게 한꺼번에 "전원 연도만 꺼내!", "전원 월만 꺼내!"라고 방송하려면 기차 전용 확성기인 .dt가 반드시 필요합니다:
    ⭕ df["입사일"].dt.year >= 2020 (30명 전체의 연도를 한 번에 뽑음)
    ⭕ df["입사일"].dt.date (30명 전체를 날짜 객체로 한 번에 바꿈)
  • 왜 df["입사일"].dt.min()은 에러가 나나요?
    .min()(최솟값)이나 .max()(최댓값)는 .dt 확성기 안에 들어 있는 기능이 아니라, 기차(Series) 자체가 원래부터 가지고 있는 기본 통계 기능입니다! 따라서 .dt.min()이 아니라 그냥 df["입사일"].min()으로 불러야 합니다.
  • 그리고 결정타! df["입사일"].min()의 결과물은 '승객 딱 1명(Timestamp 낱개)'이다!
    30명 중에서 가장 일찍 입사한 날짜 딱 1개(2005-04-15 00:00:00)가 뽑혀 나왔습니다. 이제 얘는 30명짜리 기차(Series)가 아니라 날짜 낱개(Timestamp)입니다! 낱개한테는 기차용 확성기(.dt)가 달려 있지 않으므로, 그냥 바로 .date()를 붙이면 끝납니다!
📌 [암기 공식] 날짜 최솟값/최댓값에서 YYYY-MM-DD만 뽑는 2가지 정답 루트:
• 루트 1 (선 최솟값 추출 ➡️ 후 날짜 변환, 가장 추천!): df["입사일"].min().date() (낱개로 먼저 뽑고 바로 .date() 호출)
• 루트 2 (선 덩어리 변환 ➡️ 후 최솟값 추출): df["입사일"].dt.date.min() (.dt.date로 30명 전체를 날짜로 바꾼 뒤 .min() 호출)

🎮 안요지 히메 (미라쿠라파크 일타강사): "코즈에 선배! 이건 1차원 줄(Series)이냐 2차원 표(DataFrame)냐의 차이예요! 나중에 2유형 머신러닝에서 scikit-learn의 스케일러(MinMaxScaler 등)에 값을 넣을 때 한 겹으로 넣으면 차원 오류(ValueError)로 펑 터져요!"

2.4. 행·열 선택의 알파와 오메가: loc vs iloc

  • df.loc[행조건(또는 행이름), 열이름]: 이름(Label)과 조건으로 고른다. 1유형 풀이에서 수십 번 되풀이해 쓰는 절대 공식이다!

    • 열 자리에 이름 하나("연봉")를 주면 Series, 이름 리스트(["이름", "연봉"])를 주면 DataFrame이 나온다.

2.5. 다중 조건 필터링(&, |, ~, isin, between)

🚨 판다스에서 조건 두 개를 묶을 때는 파이썬의 and / or / not을 쓰면 에러가 난다! 반드시 & (그리고), | (또는), ~ (아닌 것) 기호를 쓰고, 각 조건을 무조건 소괄호 (조건A) & (조건B)로 감싸야 한다! 괄호를 빼먹으면 연산자 우선순위가 꼬여서 엉뚱한 오류가 터진다.
  • ~ (물결표, 부정 연산자): 조건을 반대로 뒤집는다. 예: ~(df["부서"] == "지원")은 지원 부서가 아닌 모든 행을 고른다.
  • .isin(["값1", "값2"]): 여러 값 중 하나에 해당하는지 검사할 때 |(or)를 길게 쓰는 대신 리스트 하나로 깔끔하게 해결한다. 예: df["직급"].isin(["과장", "부장"]).
  • .between(작은값, 큰값): 숫자나 날짜가 특정 범위 안에 있는지 검사한다. 양 끝 경계값을 모두 포함(이상 ~ 이하)하므로 매우 직관적이다!

2.6. 결측치 다루기(isna, fillna, dropna)와 평균 대체의 원리

  • 결측치 개수 세기: df.isnull().sum() (또는 df.isna().sum())을 찍으면 열별 빈칸 개수가 나온다. 뒤에 .sum()을 한 번 더 붙이면 표 전체의 총 빈칸 개수다.
  • df["열"] = df["열"].fillna(값) (채우기): 빈칸을 지정한 값으로 메운다. 결과를 다시 원래 열에 대입(=)해야 표에 반영된다!
    • 왜 평균으로 채워도 평균 자체는 그대로일까?: 예를 들어 [1, 3, NaN]의 관측값 평균은 (1+3)/2 = 2.0이다. 빈칸에 평균값인 2.0을 채워 넣어 [1, 3, 2.0]을 만든 뒤 다시 평균을 내도 (1+3+2)/3 = 2.0으로 평균 자체는 변하지 않는다! (단, 데이터 개수가 늘어나고 편차가 줄어들므로 표준편차는 달라진다! 또한 중앙값이나 0으로 채울 때는 평균도 바뀐다).
  • df.dropna() (버리기): 빈칸이 하나라도 있는 행을 통째로 버린다. 특정 열에 빈칸이 있을 때만 버리려면 df.dropna(subset=["근속연수"])처럼 적는다. 문제 발문이 "결측치가 있는 해당 직원을 삭제한 뒤~"라고 하면 무조건 이 모양이다!

2.7. 기술통계와 표준편차의 함정(pandas ddof=1 vs numpy ddof=0)

👑 나카스 카스미 (1학년 후배): "아유무 선배님! 분명히 똑같은 연봉 데이터로 표준편차를 구했는데, 왜 판다스 df['연봉'].std()랑 넘파이 np.std(df['연봉'])의 소수점 숫자가 다르게 나오는 건가요?! 혹시 컴퓨터가 고장 난 건가요?!"

🎀 우에하라 아유무 (일타 강사): "카스미 쨩, 컴퓨터 고장 난 거 아니야! 통계학에서 표준편차는 $n-1$로 나누는 표본표준편차(ddof=1)와 $n$으로 나누는 모표준편차(ddof=0) 두 가지가 있거든! 판다스와 넘파이의 기본 설정값이 서로 반대라서 그래!"

  • 기본 집계 함수: .mean()(평균), .median()(중앙값), .min() / .max()(최소/최대), .sum()(합계), .count()(결측치가 아닌 실제 값의 개수 — 빈칸까지 다 세는 len(df)와 다르다!).
  • 사분위수 (.quantile()): .quantile(0.25)는 1사분위수(Q1), .quantile(0.5)는 중앙값(Q2), .quantile(0.75)는 3사분위수(Q3)다.
  • 표준편차 자유도(ddof) 절대 주의:
    • 판다스 df["열"].std(): 기본값이 ddof=1 (표본표준편차, $n-1$로 나눔)이다. 빅분기 실기에서 "표본표준편차를 구하시오"라고 하면 그냥 판다스 .std()를 쓰면 된다!
    • 넘파이 np.std(df["열"]): 기본값이 ddof=0 (모표준편차, $n$으로 나눔)이다. 이 차이 하나로 소수 둘째~넷째 자리가 어긋나서 오답이 되므로, 발문이 어느 쪽을 요구하는지 반드시 확인하자!

2.8. 범주형 탐색(nunique, unique, value_counts, drop_duplicates)

  • .nunique() vs .unique(): .nunique()는 서로 다른 고유값이 몇 종류(숫자)인지 알려주고, .unique()는 그 고유한 값들의 목록 자체(배열)를 준다. (단, unique()는 데이터에 등장한 순서대로 나오므로 답안으로 쓸 땐 sorted(...)로 정렬해 고정하는 것이 안전하다).
  • .value_counts(): 범주형 열을 처음 볼 때 무조건 찍는 함수! 각 값이 몇 번 나오는지 세어 많은 순서대로 정렬해 준다. 괄호 안에 normalize=True를 넣으면 개수 대신 전체 대비 비율(합이 1)을 준다. 또한 결측치(NaN)가 몇 개인지까지 포함해서 세고 싶다면 dropna=False 옵션을 넣는다!
  • df.drop_duplicates(subset=["열1", "열2"]): 지정한 열들의 조합이 똑같은 중복 행을 제거하고 첫 번째 행 하나만 남긴다.

2.9. 그룹별 집계(groupby, reset_index, agg)와 정렬(sort_values, nlargest)

  • df.groupby("묶을열")["계산할열"].계산(): 한국어 읽는 순서 그대로 쓰면 된다! 예: df.groupby("부서")["연봉"].mean() ➡️ "부서별로 묶어서 연봉의 평균을 구해라".
    • 그룹 집계 결과의 왼쪽에는 부서 이름이 인덱스로 올라간다. 뒤에 .reset_index()를 붙이면 인덱스가 다시 평범한 열로 내려온 깔끔한 DataFrame 표가 된다.
    • .agg(["count", "max"]): 리스트로 여러 통계 함수를 주면 한 번에 다 계산해서 표로 만들어준다.

2.11. 표 합치기(pd.merge), 교차표(pivot_table vs crosstab), 파생변수(np.where, pd.cut)

  • pd.merge(왼쪽표, 오른쪽표, on="공통열", how="방식") — 옆으로 표 붙이기(VLOOKUP):
    • how="inner" (기본값): 양쪽 표에 모두 존재하는 키만 남긴다.
    • how="left": 왼쪽 표의 행을 전부 남기고, 오른쪽 표에 짝이 없으면 NaN을 채운다.
    • how="outer": 양쪽 표의 모든 키를 하나도 빠짐없이 다 남긴다. (예를 들어 dept.csv의 '물류' 부서에는 직원이 0명이라 inner와 left는 30행이지만, outer로 합치면 짝 없는 물류 부서 한 줄이 더 붙어 31행이 된다!). 병합 직후에는 반드시 행 수를 찍어 검산하자!
  • 교차표 쌍둥이 — pivot_table vs pd.crosstab:
    • df.pivot_table(index="세로열", columns="가로열", values="계산할열", aggfunc="mean"): 두 범주를 세로·가로에 놓고 칸마다 특정 수치 열의 평균, 합계 등을 계산할 때 쓴다.
    • pd.crosstab(df["세로열"], df["가로열"]): 빈도(개수) 세기 전용 피벗이다! values도 aggfunc도 필요 없다. (참고로 제3유형 카이제곱 독립성 검정의 입력값이 바로 이 crosstab 표다!).
  • 파생변수 생성 3대장 (없는 열 이름에 값을 대입하면 새 열이 생긴다!):
    • np.where(조건, 참일때값, 거짓일때값): 엑셀의 IF 함수와 똑같다. 조건에 따라 두 값 중 하나를 초고속으로 채운다.
    • pd.cut(열, bins=[경계1, 경계2, 경계3, 경계4], labels=["이름1", "이름2", "이름3"]): 연속형 숫자를 구간으로 쪼개어 등급 이름표를 붙인다. 경계값(bins) 개수는 항상 구간 이름(labels) 개수보다 1개 더 많아야 한다! (예: 기둥 4개를 세워야 사이 공간이 3칸 생긴다).
    • 열 이름 변경 및 삭제: df.rename(columns={"옛이름": "새이름"}), df.drop(columns=["버릴열"]).
