1. 개요 [편집]

효빈위키의 문법 중 응용 문법, 특수한 상황에 사용되는 문법, 난도가 높은 문법들을 설명합니다. 편집에 필수적으로 필요한 기본 문법들은 상위 문서에 안내되어 있으니 심화 문법을 보기 전에 기초 내용을 먼저 숙지하시는 것을 권장합니다.

2. {{{#!wiki }}} 구문을 활용한 CSS 적용 [편집]

{{{#!wiki }}} 구문에서, style 선언과 dark-style 선언을 사용하여 CSS의 많은 속성을 적용시킬 수 있습니다. 다만, 후술하다시피 모든 속성과 함수를 적용하고 사용할 수 있는 것은 아닙니다. 기본 형식은 아래와 같으며 선언 다음에 개행을 생략하면 정상적으로 출력되지 않습니다.
{{{#!wiki style="속성들" dark-style="다크모드 전용 속성들" 속성이 적용된 내용}}}
속성들 부분은 "속성명1: 값1; 속성명2: 값2;" 와 같은 방식으로 구성되며, 각 속성의 항목은 세미콜론(;)으로 끝납니다. 즉, 여러 속성끼리는 ; 문자로 구분합니다. 자세한 내용에 대해서는 CSS 문서의 문법 문단을 참고하시기 바랍니다.
다크모드 전용 선언인 dark-style인 경우 style 선언도 그대로 적용되고 다크모드 모드인 경우 추가적으로 해당 선언이 적용됩니다. 기존 style 선언이랑 겹치는 경우 dark-style 선언이 우선시됩니다.
style 선언dark-style 선언
라이트모드적용비적용
다크모드2순위 적용1순위 적용
본 문단의 하위 항목인 '텍스트 정렬 및 자간 조절', '줄바꿈 기준 설정', '텍스트 및 셀 배경의 그라데이션 효과' 뿐 아니라, 후술되는 '이미지/동영상 삽입 관련 고급 문법', '인용문 정렬 문법', '접기 시 미관 개선용 문법'은 CSS에 존재하는 다양한 속성 중 일부을 효빈위키의 필요성에 맞게 활용한 예시들입니다. 따라서 자세한 내용은 CSS에 관련된 외부 자료를 참고하시기 바랍니다.
단, {{{#!wiki }}} 문법으로 문단 문법(== 문단 ==)을 감쌀 수 없습니다. 문단 내에서 {{{#!wiki }}} 문법을 사용하시기 바랍니다.
{{{#!wiki lang="(언어 코드)" 속성이 적용된 내용}}}
추가로 lang 속성을 {{{#!wiki }}} 구문에 적용할 수 있습니다. 언어 코드에는 ko(한국어), ja(일본어), zh(중국어) 등을 입력할 수 있습니다. 이와 관련한 내용은 틀:zh의 설명문서의 글꼴 지정이 필요한 이유를 참고하세요.
  • 주의: {{{#!wiki }}} 구문은 기본적으로 block(줄 전체를 차지하는) 요소로 취급됩니다. 줄 전체를 차지하는 것이 싫으시다면 style 선언에 display: inline;을 추가하는 등의 방법으로 해결해야 합니다.
  • 주의: <div> 태그를 제외한 HTML의 다른 모든 태그, 특히 <span> 태그를 사용하는 문법은 정식 문법이 아니며 가능한 한 사용을 자제할 것이 요구됩니다. {{{#!wiki style= ...}}}로 시작하지 않고, {{{#!html ...}}}로 시작하는 모든 문법은 모두 비권장이라 보시면 됩니다. 이에 관해서는 별도 문단에서 설명합니다.
  • 주의: 전술하였다시피, 모든 CSS 속성들이 사용 가능한 것은 아닙니다. 일부 CSS 속성 및 함수의 경우 보안 등의 문제로 인해 지원하지 않으며, 사용하려고 해도 속성이 적용되지 않습니다. 이에 대해서는 CSS 문서 내 효빈위키에서 사용 가능한 속성 문단을 참고하시기 바랍니다.
  • 주의: CSS 속성값 내용이 너무 길면 적용되지 않을 수 있으며, 특히 ','(콤마) 갯수를 13개를 초과하여 작성하면 해당 속성은 적용되지 않습니다.

2.3. 줄바꿈 기준 설정 [편집]

틀, 표, 인용문 박스 등 특정 영역의 가장자리에서 텍스트가 줄바꿈 될 때의 기준을 다음 문법을 통해 설정하여 가독성을 향상시킬 수 있습니다.
{{{#!wiki style="word-break: (조건값)" (텍스트)}}}
  • normal: 띄어쓰기와 하이픈(-)을 단어 구분의 기준으로 라틴 문자(로마자)의 단어 단위 줄바꿈
  • keep-all: 띄어쓰기와 하이픈(-)을 단어 구분의 기준으로 모든 문자(한글 포함)의 단어 단위 줄바꿈 (표 안 텍스트의 경우 <keepall>, <rowkeepall>, <colkeepall> 사용 권장)
  • break-all: 글자 단위 줄바꿈
참고: 이 문법을 따로 사용하지 않았을 경우의 효빈위키 기본값은 글자 단위 줄바꿈(break-all) 입니다.
이 문법을 사용하여 해당 영역에서 전체적으로 단어 단위로 줄바꿈을 적용할 시, 예외적으로 일부 단어에 대해서만 단어 내 특정한 위치에서 줄바꿈을 적용하려면 그 위치에 폭 없는 공백(Zero Width Space, U+200B)을 삽입하면 됩니다. 폭 없는 공백은 그냥 복사해서 붙여넣으면 나중에 RAW에서 찾기 어려워지니 {{{#!html &ZeroWidthSpace;}}} 또는 {{{#!html &#8203;}}}과 같이 HTML을 사용한 방법이 좋습니다.

2.5.1. 텍스트 그림자 및 네온 효과 [편집]

일반적인 경우 틀:글무리를 이용하면 됩니다. 예시는 다음과 같습니다.
입력출력
[include(틀:글무리, 둘레=3, 그림자=00f, 글자=fff, 내용=여기로, 링크=효빈위키)]여기로
단, 다중 그림자 효과를 적용하는 상황처럼 부득이하게 필요한 경우 아래와 같은 문법을 이용할 수 있습니다.
{{{#!wiki style="text-shadow: 가로움직임px 세로움직임px 번짐정도px #그림자색; color:#글자색" 서술할 내용}}}
효빈위키에서는 px 단위의 값이 0이 아닐 때 항상 px를 써주어야 정상 표시됩니다. 표나 이미지의 크기를 정할 때와 같이, px를 생략하면 자동으로 픽셀 단위로 맞추어 주지는 않음에 주의해야 합니다. 글자색을 그대로 쓸 생각이면 ; color:#글자색부분을 제외하면 됩니다.
{{{#!wiki style="text-shadow: 3px 3px 0 #999"
그림자 효과}}}

3. {{{#!style }}} 구문을 활용한 클래스 기반 전역 스타일 지정 [편집]

{{{#!wiki style=""}}} 구문이 인라인(inline)으로 구문 내에 CSS 스타일을 부여하는 것과는 달리, {{{#!style }}} 구문은 전역으로 CSS 스타일을 부여합니다. HTML에서의 <style> 태그의 사용례와 같습니다. 효빈위키 전용 쿼리로 @theseed-dark-mode를 지원합니다. 이 쿼리로 감싼 선택자는 다크모드에서만 적용됩니다.
{{{#!style .red { background-color: red; color: white; } @theseed-dark-mode { .red { background-color: green; } } }}}
위와 같이 red 클래스를 쿼리 밖과 안에서 동시에 선언하게 된다면, 라이트 모드일 때는 쿼리 밖의 배경색은 빨간색, 글자 색상은 흰색 스타일이 적용되며, 다크 모드일 때는 쿼리 안의 배경색은 초록색, 글자 색상은 흰색[4]의 스타일이 적용됩니다.
  • 주의: {{{#!style }}} 구문 내에서 선택자 중첩은 지원하지 않습니다.
  • 주의: {{{#!style }}} 구문 내에서 @media 쿼리 등은 지원하지 않습니다.
  • 주의: [include()] 문법으로 특정 문서의 {{{#!style }}}을 가져올 수 없습니다.
  • 주의: 모든 CSS 속성들이 사용 가능한 것이 아닙니다.

4.1. 앵커(anchor) [편집]

[anchor()]문법을 사용하면 현재 문서 또는 다른 문서의 임의의 위치로 하이퍼링크를 걸 수 있습니다. 도착점에 [anchor(아무개)]를 삽입하고, 출발점에 [[효빈위키:문법 도움말/심화#아무개]]처럼 연결합니다. 특정한 위치에 자동으로 생성되는 앵커도 있습니다. (#toc, #s-문단번호, #문단명[5], #fn-각주번호 등) 같은 이름을 가진 문단이 2개 이상 있을시, 앵커가 적용되지 않으니 #s-문단번호 방식으로 링크하거나, 앵커 이름을 다르게 해야 합니다.[A]

4.2. 제목에 |, \, #가 쓰이거나 ]로 끝나는 문서, /로 시작하는 문서로 하이퍼링크 걸기 [편집]

정식 이름공간이 아닌 인수를 쓸 경우 모든 문서의 개수가 출력됩니다. 예: [pagecount(더미)][19] → 8398529

9.2. 루비 문자(ruby) [편집]

루비 문자(후리가나)를 입력합니다. 단, 매크로 내 컬러 지정은 윗첨자에만 적용됩니다. Ruby 코딩 용도로 사용할 수 없습니다[20]. 예시: [ruby(글자,ruby=루비,color=red)] → 글자루비

10. 테이블 응용 문법 [편집]

10.1. 테이블 캡션 [편집]

10.2. 이미지 / 동영상 삽입 시 기본 셀 여백 제거 [편집]

이미지 또는 동영상과 같은 콘텐츠를 셀 안에 삽입할 때 생기는 상하 5px[21], 좌우 10px[22]의 기본 셀 여백을 <nopad>가 아닌 {{{#!wiki style="margin: -5px -10px" }}} 문법으로도 제거할 수 있습니다.[23]

10.3. 이미지 삽입 시 최대 너비값 설정하기 [편집]

10.4. 이미지 삽입 시 스케일링 방식 설정 [편집]

image-rendering: [설정값] 속성을 이용하여 웹 브라우저가 이미지를 스케일링 할 때에 쓰는 알고리즘을 지정할 수 있습니다. (auto, crisp-edges, smooth, high-quality, pixelated)

10.5. 테이블 여러 개 나란히 배치하기 [편집]

<tablealign> 문법을 사용하여 테이블을 두 개 이상 가로로 나란히 배치해야 할 때가 있습니다. 첫 번째 혹은 모든 테이블에 대해 wiki 문법을 사용해 감싸면 개행을 방지하면서 여러 테이블을 나란히 배치할 수 있습니다. 왼쪽/중앙 정렬된 테이블의 경우 부모 요소에서 텍스트 중앙 정렬(또는 text-align: left)을 하여 해결할 수 있습니다.

11. 접기의 응용 [편집]

표 내에서 접기를 이용해 표를 추가로 넣을 때 상당히 넓은 여백이 생기는데, 이 여백을 wiki 틀 문법으로 제거할 수 있습니다. 표의 한 칸에 여러 접기 틀을 합쳐 넣을 수 있으며, 버튼 대괄호 좌우에 점자 패턴 공백이나 전각 공백[24]을 넣으면 그 크기만큼 간격이 생깁니다. Flexbox를 사용하여 접기 버튼 사이의 간격을 일정하게 만들 수도 있습니다. 내부 접기들 안의 표 바깥 여백은 margin 속성을 조절하여 제거합니다.[25]

{{{#!html (코드)}}} 형태로 작성합니다. 코드를 열었다면 무조건 닫아야만 적용됩니다.

13.1. HTML 문법 무효화 [편집]

{{{#!html 서술할 내용}}}을 통해 \를 적용한 것처럼 문법을 무효화하여 텍스트 그대로 출력하게 만들 수 있습니다.[26]

{{{#!wiki style="border: 1px solid gray; border-top: 5px solid orange; padding: 12px" {{{+1 여기에 제목을 넣어주세요.}}}[br][br]여기에 내용을 넣어주세요.}}}
테두리를 지정합니다. (색 코드) 부분에 원하는 색깔의 코드를 넣어 주면 됩니다. orange(가장 일반적인 색, 주의 문구), crimson(조금 더 강한 경고), black(제한적 이용 경고 등), navy(더 강한 경고), gray(폐지, 부재), yellowgreen(편집 주의), #FF7777(선정성 알림) 등이 쓰입니다.

16. 매개변수 [편집]

일반 틀, 기호 틀, 양식상자 틀, 기타 문법 틀 등에서 매개변수를 설정할 때 @매개변수@ 꼴로 선언할 수 있습니다. 값을 입력할 때 쉼표가 있을 경우 백슬래시를 붙여 \,로 씁니다. 디폴트 매개 변수는 @매개변수=디폴트값@ 형태로 선언합니다.[27]
주의: 효빈마크(효빈위키 자체 문법)에는 매개변수를 사용할 수 없습니다. 예: <bgcolor=@배경색=#00a495@> 사용 불가.

16.1. 상수 [편집]

상수 calleeTitle은 include로 호출한 문서의 이름을 받아 옵니다. 주의: calleeTitle은 상수이므로 사용자가 별도로 선언하더라도 '호출한 문서의 이름'으로 덮어 써집니다.

17. if 문법 [편집]

주어진 표현식이 참 또는 참에 준하는 값으로 평가될 때, if 문법 내부의 내용이 출력되는 조건문입니다. 문자열은 큰따옴표와 작은따옴표 둘 다 사용할 수 있습니다. 수치형 변환을 위해 (+num), (num * 1.0) 등을 사용합니다.
주의할 점은 이렇게 변환할 경우 매개변수가 설정되지 않았거나[28] 빈 문자열일 경우[29] 값이 0이 되기 때문에, 숫자 비교 조건에 0이 포함될 경우 추가 조건 설정이 필요할 수 있습니다.
if 문법에서는 틀로 넘겨진 모든 매개변수를 this 키워드로도 참조할 수 있습니다. (예: this['매개변수'+idx])[30]

17.1. 진리값 [편집]

true, false로 평가됩니다. 거짓값(falsy)으로는 0, null, ""(공문자열), NaN 등이 있으며 나머지는 대부분 참값(truthy)입니다. Infinity, -Infinity는 참값입니다.

17.2. 대입 연산 [편집]

If 문법에서 변수를 선언하고 대입 연산을 진행할 수 있으며(=, +=, ||= 등), 이하 if 문법 선언 시에도 계속 유지됩니다. 이를 응용하여 else if나 else 문법처럼 구현할 수 있습니다.[31]

17.3. 비교 연산 [편집]

==, !=, >, >=, <[0포함조건], <= 연산자를 지원합니다.

17.4. 논리 연산 [편집]

&&(논리곱), ||(논리합), !(부정) 연산자를 지원합니다. 비트 연산자와 혼동되지 않도록 주의하세요.

17.5. 산술 연산 [편집]

+, -, *, /, %, ** 연산자를 지원합니다. 나눗셈 계산 시, 정수부분만을 구하는 나눗셈임에 주의하세요.

17.6. 증가 연산, 감소 연산 [편집]

++, -- 연산자를 변수 앞이나 뒤에 두어 사용합니다.

17.7. 비트 연산 [편집]

~, <<, >>[37], &[우선순위], |[우선순위], ^[우선순위] 연산자를 지원합니다.

17.8. 조건부 연산 [편집]

(조건식)?(참일 경우):(거짓일 경우) 형태로 나타냅니다. 이를 활용하여 연쇄적인 if...else if...else문을 한 줄로 구현할 수 있습니다.

17.9. 함수, 메서드 및 속성 [편집]

문자열 관련 length, indexOf()[38], lastIndexOf(), startsWith(), endsWith(), substring(), trim(), substr(), toString() 메서드를 지원합니다. 전역 함수로는 parseInt(), time()을 지원합니다.

17.10. 배열과 객체 [편집]

배열 ['사과', '배', '참외'], 객체 {'사과': 36, '바나나': 51} 형태로 활용할 수 있습니다. 배열의 길이나 객체 속성 개수는 구할 수 없습니다.

17.11. 행 매개변수 <rowif>와 함께 사용하기 [편집]

<rowif=이름> 형태로 사용하여, 해당 매개변수가 존재할 때만 행이 토글되도록 할 수 있습니다. (프로필 표 구현에 용이) 주의: rowif 문법 내에서 >, >= 연산자를 사용할 수 없습니다.

18. 구문 강조 (syntax highlighting) [편집]
