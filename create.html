편집 도우미

📄 텍스트 꾸미기

  • '''굵게'''
    → 굵게
  • ''기울임''
    → 기울임
  • __밑줄__
    → 밑줄
  • --취소선--
    → 취소선

🔗 링크 및 구조

  • [[문서명]]
    → 기본 링크
  • [[링크|출력명]]
    → 이름 변경
  • == 제목 ==
    → 대문단
  • === 제목 ===
    → 중문단
  • * 내용
    → 점 목록

🧩 고급 기능

  • [각주]
    → 맨 아래 각주 표시
  • <br>
    → 줄바꿈
  • 우측 상단 양식 불러오기를 쓰면 복잡한 표를 쉽게 만들 수 있습니다.
