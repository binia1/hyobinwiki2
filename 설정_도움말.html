1. 개요 [편집]

the seed 엔진은 사용자들이 기능과 레이아웃을 사용자 본인에게 맞게 변경할 수 있도록 설정 기능을 제공하고 있습니다. 이 문서는 설정 창과 각 설정들에 대해서 설명합니다.

1.1. 설정 페이지 [편집]

최상단의 내비게이션 바 우측에 있는 설정 버튼을 클릭하시면 설정 모달 창이 나타납니다.

2. 위키 [편집]

2.1. 테마
  • 자동 (시스템 설정) (기본값)
  • 라이트
  • 다크
라이트 / 다크로 설정하는 경우, 기기 설정에 상관없이 다크 테마 사용 활성화 혹은 비활성화 시킬 수 있습니다.
2.2. 내용과 링크가 다른 링크 펼치기
  • 사용
  • 미사용 (기본값)
링크 내용과 실제 대상이 다른 경우 그 내용을 펼쳐서 보여줍니다.
2.3. 표 워드랩 사용 안 함
  • 사용
  • 미사용 (기본값)
표의 워드랩을 비활성화합니다. 모바일 환경에서 표 내용이 많은 경우 세로쓰기 현상이 발생하는 걸 방지하고, 스크롤이 가능하게 합니다.
2.4. 문단 접기
  • (기본) (기본값)
  • 모든 문단을 접기
  • 모든 접힌 문단을 펼치기
모든 문단을 접기로 설정하면 접기 문법이 적용되지 않은 문단도 자동으로 전부 접힌 상태가 됩니다. 모든 접힌 문단을 펼치기로 설정하면 접기 문법이 적용된 문단도 자동으로 펼쳐진 상태가 됩니다.
2.5. 접기 문법을 기본으로 펼치기
  • 사용
  • 미사용 (기본값)
사용 시, #!folding 문법이 적용된 내용을 기본으로 펼쳐져 있는 상태로 만드는 기능입니다. 문단이 접혔거나 목차가 접힌 것을 자동으로 펼쳐지지 않습니다.
2.6. 접기 문법의 애니메이션 비활성
  • 사용
  • 미사용 (기본값)
접기 문법으로 인하여 이용자가 클릭을 통해 접고 펼치는 과정에서 보이는 애니메이션을 비활성화할 수 있는 기능입니다. 해당 설정 변경 시, 새로고침을 해야 정상적으로 설정이 반영됩니다. 저사양 기기인 경우 애니메이션 작동에 있어서 성능 저하가 발생하는 경우, 해당 설정을 통해 애니메이션 비활성화를 할 수 있습니다.
2.7. 취소선
  • 보이기 (기본값)
  • 취소선 제거
  • 숨기기
본문에 존재하는 글자 위의 취소선을 제거하거나, 취소선이 그어진 글자 자체를 지울 수 있습니다.
2.8. 각주 표시 형식
  • 브라우저 기본
  • 팝오버 (기본값, PC)
  • 팝업 (기본값, 모바일)
  • 펼침
각주 표시 형식을 변경합니다. 기본 선택은 각주 링크를 클릭 시 각주 목록으로 내려가 직접 보게 됩니다. 팝오버 선택은 각주 위에 마우스를 올리면 위에 각주 내용이 뜹니다. 팝업 선택은 팝업창 형태로 각주를 표시합니다. 펼침 선택은 각주의 내용을 본문 내에 펼쳐서 보여줍니다. 평소에 모든 각주를 다 보는 경우 쓰면 좋습니다.
2.9. 이미지
  • 보이기 (기본값)
  • 숨기기
  • 1MB 이상 이미지 숨기기
이미지를 숨기거나, 숨길 방법을 지정합니다. 보이기 선택은 이미지를 항상 불러옵니다. 숨기기 선택은 이미지를 숨기는 대신 숨긴 이미지를 펼칠 수 있는 버튼을 보여줍니다. 1MB 이상 숨기기 선택은 크기가 1MB 이상인 이미지만 '숨기기' 옵션의 효과를 가집니다. 그 외의 경우는 보여줍니다.
2.10. 이미지 lazy load 비활성화
  • 사용
  • 미사용 (기본값)
2.11. 분류 위치
  • 상단 (기본값)
  • 하단
  • 모두
분류의 위치를 조정할 수 있는 설정입니다. 기본 설정은 '상단'이며 상단으로 설정 할 시에 최근 변경 시간 아래에 분류가 표시됩니다. '하단'으로 설정하는 경우, 문서 맨 하단 CCL 설명란 위에 분류가 표시됩니다. 하단에 표시되는 경우 분류의 갯수와 상관 없이 무조건 펼쳐진 상태로 표시됩니다. '모두'로 설정하는 경우 상단과 하단 두 곳 전부 표시됩니다.
2.12. 글자 크기
  • 사용하지 않음 (기본값)
  • 더 작게
  • 작게
  • 크게
  • 더 크게
  • 매우 크게
효빈위키 본문의 글꼴 크기를 변경합니다. 글자가 잘 보이지 않는 경우와, 그 반대의 경우에 사용하면 좋습니다. (본 사이트는 설정 모달에서 슬라이더 형태로 제공하고 있습니다.)
2.13. 기본 편집 모드
  • 자동 기본
  • 편집기 (자동값 - PC)
  • Plain 편집 (자동값 - 모바일)
편집 페이지에서 편집기를 불러올 때 어떤 편집기로 불러오는지 설정할 수 있습니다. 일반 편집기는 편집기 상단에 글자 크기나 색상 등 글자 서식을 지정할 수 있는 버튼 등이 있고 서식이 어떻게 작동이 되는 건지[1] 정리해주며 자동으로 위키 문법으로 전환해주는 기능이 있습니다. Plain 편집기는 RAW를 직접 입력하는 방식으로 위키 문법 적용이 필요한 경우 직접 이해하고 사용해야 합니다.
2.14. 항상 외부 아이콘을 표시하기
  • 사용
  • 미사용 (기본값)
텍스트 없이 어떤 목적지로 연결되는지 충분히 알 수 있는 아이콘인 경우 위키 측에서 하이퍼링크 아이콘을 안보이게 설정[2]할 수 있는데, 해당 설정을 무시하고 외부 아이콘을 보이게 하는 설정이다.
2.15. 상대 표기 시간을 사용하지 않음
  • 사용
  • 미사용 (기본값)
최근 변경, 최근 토론, 사이드바에서 상대적인 시간 표기를 원하지 않을 경우 해당 설정을 활성화하여 절대 시간 표기를 사용할 수 있습니다. n초 전, n일 전 같은 표기가 사용자 브라우저 시간대에 맞는 시간대로 변경됩니다.

4. 스킨 [편집]

스킨 탭에는 사이트 레이아웃과 관련된 설정들이 모여있습니다. 사용 중인 스킨마다 다른 설정이 있습니다. 현재 효빈위키에서는 공식 스킨인 espejo 스킨과 외부에서 제공하는 liberty 스킨이 있습니다.

4.1. espejo 스킨 (기본 스킨) [편집]

4.1.1. 외관 [편집]

스킨 외관 부분에 해당됩니다.
  • 검은 화면으로: AMOLED 디스플레이를 사용하는 기기의 번인 방지를 위한 기능으로, 다크 테마의 배경색을 회색에서 검정색으로 변경하는 설정입니다.
  • 글꼴: 자동 (기본값), 브라우저 기본, Noto Sans Korean, Noto Serif Korean, 나눔고딕, 나눔바른고딕, 마루부리, Pretendard JP, Apple SD Gothic Neo[*], 맑은 고딕[*] 등 효빈위키의 글꼴을 변경합니다.
  • 저는 기념일에 관심이 없습니다: 크리스마스나 만우절 등의 기념일 마다 스킨이 일부 변경되는데 원래의 스킨으로 보고 싶은 경우 활성화합니다. 기념일 스킨이 진행중일 때 나타납니다.

4.1.2. 네비게이션 바 [편집]

  • 고정형 내비게이션 바: 상단의 내비게이션 바를 고정형으로 변경합니다. 마우스 스크롤을 통해 밑으로 내려도 내비게이션 바가 따라옵니다. 모바일 환경 등, 메뉴 접근성이 떨어지는 경우 사용하면 좋습니다. (기본값: 미사용)

4.1.3. 사이드바 [편집]

  • 배치: 기본 (기본값), 왼쪽, 세로형. 본 설정은 PC나 태블릿처럼 좌우 공간이 확보되어 우측 사이드바가 있는 경우에만 작동합니다. 기본은 사이드바가 우측에 있으며, '왼쪽' 설정시 우측 사이드바를 좌측으로 옮깁니다. 세로형 설정시 문서 하단으로 이동합니다.
  • 실시간 검색어 항상 펼치기: 실시간 검색어 박스를 항시 펼치도록 하는 설정입니다. 기본값으로 설정하는 경우 마우스를 올려야지만 실시간 검색어를 확인할 수 있습니다.

4.1.4. 내비게이션 컨트롤 [편집]

  • 비활성화: 우측 하단 '맨 위로', '맨 아래로', '목차 버튼' 기능을 담당하던 내비게이션 컨트롤 기능을 비활성화하는 기능입니다. 해당 설정 비활성화시 목차 버튼과 각주 버튼에 대해 상호작용을 할 수 없는 상태가 됩니다.
  • 목차 버튼: 기본, 팝업, 링크, 비활성화. '기본'으로 설정이 된 경우, 목차 지도 기능이 활성화되지 않는 환경에서는 '팝업'으로 작동되고 활성화되는 환경에서는 '링크'로 작동합니다. 팝업으로 설정 시 팝업 창을 통해 목차를 바로 열어서 이동할 수 있습니다. 링크는 #toc 문법을 사용한 것과 같습니다.
  • 각주 버튼(실험실): 기본, 팝업, 링크. 해당 기능은 실험실 설정에서 활성화하여야 동작합니다. 팝업으로 설정 시 팝업 창을 통해 각주를 바로 열어서 확인할 수 있습니다. 링크는 각주를 모아 놓는 문서 하단으로 이동시켜줍니다.

4.1.5. 문서 [편집]

  • 목차 지도: 활성화 (기본값), 강제 활성화, 비활성화. PC 환경에서 페이지 폭이 큰 경우 오른쪽에 '목차 지도' 기능을 통해 문서를 읽는 도중 우측 공간에 표시들이 나타나며, 마우스를 올리는 경우 문단명을 확인 할 수 있고 클릭하면 해당 문단으로 이동합니다. 강제 활성화 시 모바일 환경이나 기기 폭이 좁아서 사용이 불가능 한 곳에서도 강제적으로 사용 가능하게 만들 수 있습니다.

4.1.6. 실험실 [편집]

여기에 해당되는 설정은 정상적인 작동을 안 할 수 있으며, 이에 따라 사이트 이용에 영향이 있을 수 있습니다.
  • 내비게이션 컨트롤 각주 버튼 활성화: 네비게이션 컨트롤에서 각주 버튼을 활성화할 수 있는 설정입니다. (기본값: 미사용)

4.2. liberty 스킨 [편집]

  • 사이드바 설정: 고정, 숨김 (기본값 - 모바일), 우측 표시 (기본값 - PC), 하단 표시. 최근 변경 사이드바를 설정할 수 있습니다.
  • 내비게이션 바 고정: 내비게이션 바를 고정할 수 있습니다. (기본값: 미사용)
