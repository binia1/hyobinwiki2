1. 개요 [편집]

효빈위키에 등록된 템플릿들의 목록입니다. 동일한 주제의 여러 문서들에 일괄적으로 적용되는 문서들을 만들 때 아래에 나열된 하위 분류 중 만들려는 문서의 주제와 어울리는 분류로 들어간 뒤, 하위 분류 내의 템플릿 목록들 중에 적절한 템플릿을 선택하여 문서의 기본적인 뼈대로 삼을 수 있게 해줍니다.
템플릿과 관련된 규정은 특수 문서 편집합의를 참고하시기 바랍니다.

2. 템플릿 생성하기 [편집]

만약 하위 분류나 하위 분류 내의 템플릿 목록들 중에 만들려는 문서의 주제에 맞는 적절한 템플릿이 없을 경우 템플릿을 직접 생성하여 적용할 문서들에 일괄적으로 적용시킬 수 있습니다.
자신이 만들려는 문서들의 주제에 맞는 "템플릿:XXX" 형식의 적절한 문서명과 함께 주제가 비슷한 문서들과 공통적으로 사용되는 부분[1]을 뽑아 템플릿 문서를 생성하면 됩니다. 그 외 효빈위키에서의 문서 작성과 위키 문법에 대한 상세한 도움말은 효빈위키:편집 도움말과 효빈위키:문법 도움말을 참고하시길 바랍니다.
"템플릿:XXX" 형식의 템플릿 문서를 만들고 난 뒤에는 반드시 생성한 템플릿 문서 최상단에 [[분류:템플릿/XXX]][2] 형식의 분류 매크로를 집어넣어 해당 문서가 템플릿 분류로 분류될 수 있도록 합니다. 만약 생성한 템플릿 문서가 "분류:템플릿/XXX" 형식의 상위 템플릿 분류로 분류되지 않는다면 귀찮더라도 "분류:템플릿/XXX" 형식의 적절한 상위 템플릿 분류 문서를 만들어서라도 해당 문서가 템플릿 분류로 분류될 수 있도록 해주시길 바랍니다. 이는 새로 생성한 템플릿 문서가 미분류되는 참사를 막기 위함입니다.
만약, 애써 새로 만든 템플릿 문서를 "분류:템플릿/XXX" 또는 "분류:템플릿" 형태의 템플릿 분류로 분류시키지 않는다면, 만들어진 템플릿 문서가 템플릿으로 분류되지 못하고 고립되어 문서를 만든 사람만 사용하는 문서로 전락하게 될 확률이 매우 높습니다. 또, 템플릿 문서를 이용해 문서를 만들려는 사람들도 템플릿 분류로 분류되지 못한 템플릿 문서들은 확인할 수도, 사용할 수도 없게 됩니다. 미분류된 템플릿 문서를 다시 찾아서 적절한 템플릿 분류로 분류하려고 해도, 템플릿 문서 작성자가 아니라면 "템플릿:XXX" 식의 문서명을 검색 자동 완성 기능을 이용해서 문서 하나하나 미분류된 문서가 있는지 검토해가며 미분류된 템플릿 문서들을 일일이 적절한 상위 템플릿 분류로 분류시키는 수밖에 없습니다.
따라서 본인이 애써 만든 문서를 본인만 사용하는 문서로 전락시키거나 나중에 검색 자동완성 기능을 이용해 미분류된 템플릿 문서를 하나하나 찾아서 적절한 상위 템플릿 분류로 분류시킬 생각이 아니라면 나중에 자신이 만든 템플릿 문서를 쉽게 확인하기 위해서라도 위에 서술한대로 새로 생성한 템플릿 문서들은 상위 템플릿 분류로 꼭 분류하도록 합니다.
그 외 효빈위키에서의 분류 기능에 대한 상세한 사용법은 효빈위키:분류 문서를 참고하도록 합시다.

3. 템플릿 사용하기 [편집]

게임 템플릿을 사용해서 새 게임 문서를 생성하려면 아래에 나열된 하위 분류들 중 분류:템플릿/게임에 해당하는 템플릿:게임이라는 문서 우측 상단의 역사 탭을 누른 후 가장 최근 버전[3]의 RAW를 누르면 나오는 소스[4]를 복사한 뒤 새로 생성할 문서에 붙여넣고 기본적인 내용을 입력하여 새 문서를 생성하면 됩니다.
템플릿을 사용해서 새 문서를 생성할 때 템플릿 문서 소스 하단의 [[분류:템플릿/XXX]] 또는 [[분류:템플릿]] 형태의 분류 매크로는 제외하고 복사하도록 합시다. 만일 분류 매크로까지 같이 복사하면 템플릿을 사용해서 만들어진 새 문서가 템플릿으로 분류되므로 유의하도록 합시다.
